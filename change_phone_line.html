คู่มือการเปลี่ยนข้อมูลการติดต่อ

ขั้นตอนการดำเนินการเมื่อเปลี่ยนเบอร์โทรศัพท์ หรือเปลี่ยนบัญชี LINE สำหรับระบบ PS33 Home System

กรณีที่ 1: เปลี่ยนหมายเลขโทรศัพท์

เนื่องจากหมายเลขโทรศัพท์ถูกใช้เป็น Username ในการเข้าระบบหลักและเชื่อมโยงกับ LINE ID ลูกบ้านจึงไม่สามารถแก้ไขเองโดยตรงได้ ต้องดำเนินการร่วมกับนิติบุคคลดังนี้:

สำหรับลูกบ้าน
แจ้งนิติบุคคล

ติดต่อเจ้าหน้าที่นิติบุคคลเพื่อขอแจ้งเปลี่ยนหมายเลขโทรศัพท์เดิมเป็นหมายเลขโทรศัพท์ใหม่

ทดสอบเข้าระบบ

หลังเจ้าหน้าที่ดำเนินการเรียบร้อย ให้ทดสอบเข้าสู่ระบบผ่าน LINE Mini App โดยใช้เบอร์โทรศัพท์ใหม่

สำหรับนิติบุคคล (ผู้ดูแลระบบ)
เข้าสู่ระบบหลังบ้าน

ผู้ดูแลระบบเข้าสู่หน้าแดชบอร์ดหลักของระบบจัดการ

แก้ไขผ่านเมนูจัดการผู้ใช้ LINE

ไปที่เมนู "ข้อมูลผู้ใช้ LINE" ค้นหาบัญชีลูกบ้านที่ต้องการ กด "แก้ไข" (Edit) เปลี่ยนเบอร์โทรศัพท์เดิมเป็นเบอร์ใหม่แล้วกดบันทึก

กรณีที่ 2: เปลี่ยนบัญชี LINE (แต่ใช้เบอร์โทรศัพท์เดิม)

กรณีเปลี่ยนเครื่องโทรศัพท์ใหม่ หรือสมัครบัญชี LINE ใหม่ แต่ยังคงใช้เบอร์มือถือเดิมที่เคยลงทะเบียนไว้ ลูกบ้านสามารถดำเนินการได้ด้วยตนเองทันที:

1เข้าหน้าระบบลงทะเบียน

ใช้บัญชี LINE ใหม่ สแกนคิวอาร์โค้ดหรือกดลิงก์ลงทะเบียนเข้าสู่ระบบ PS33 เพื่อเข้าหน้าสมัครสมาชิก

2กรอกข้อมูลเดิม

ระบุเลขที่บ้าน ชื่อ นามสกุล และช่องเบอร์โทรศัพท์ให้ใส่ "หมายเลขโทรศัพท์เดิม" ที่เคยลงทะเบียนไว้

3ยืนยันรหัสผ่าน

กรอก "รหัสผ่านเดิม" ที่เคยตั้งไว้ตอนสมัครครั้งแรก เพื่อยืนยันความเป็นเจ้าของบัญชี

4ระบบทำการโอนย้ายบัญชี

เมื่อกดลงทะเบียน ระบบจะตรวจพบรหัสผ่านและเบอร์โทรเดิม จากนั้นจะทำการยกเลิกการเชื่อมโยงกับ LINE Account เดิม และผูกบัญชีเข้ากับ LINE Account ใหม่ให้ทันที โดยข้อมูลการเงินและประวัติการแจ้งซ่อมของท่านจะยังอยู่ครบถ้วน

กรณีที่ 3: เปลี่ยนทั้งบัญชี LINE และเบอร์โทรศัพท์ใหม่

เพื่อความปลอดภัยของข้อมูลและป้องกันความซ้ำซ้อนในฐานข้อมูล ลูกบ้านและนิติบุคคลต้องร่วมกันดำเนินการดังนี้:

1แจ้งนิติบุคคลลบบัญชีเดิม

ลูกบ้านแจ้งเจ้าหน้าที่นิติบุคคลเพื่อให้ทำรายการลบ (Delete) บัญชีผู้ใช้ LINE และบัญชีผู้ใช้เดิมออกผ่านเมนู "ข้อมูลผู้ใช้ LINE" หลังบ้าน เพื่อล้างการเชื่อมโยงระบบเดิม

2ลงทะเบียนใหม่

หลังจากที่เจ้าหน้าที่ลบข้อมูลเดิมออกแล้ว ให้ลูกบ้านนำบัญชี LINE ใหม่ทำการลงทะเบียนใหม่ทั้งหมดผ่านหน้าระบบลงทะเบียน โดยใช้เบอร์โทรศัพท์ใหม่ได้ทันที

คำแนะนำเพิ่มเติม
  • หากลูกบ้านลืมรหัสผ่านเดิมในการทำขั้นตอนย้าย LINE เจ้าหน้าที่นิติบุคคลสามารถช่วยรีเซ็ตรหัสผ่านใหม่ให้ผ่านหน้าจัดการหลังบ้านได้
  • ข้อมูลสำคัญ เช่น ยอดค้างชำระ ประวัติการชำระเงิน และการแจ้งซ่อมย้อนหลังจะอิงตามเลขที่บ้าน ดังนั้นการเปลี่ยนเบอร์โทรศัพท์หรือ LINE จะไม่มีผลทำให้ข้อมูลเหล่านี้สูญหาย
