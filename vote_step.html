คู่มือขั้นตอนการทำงานและติดตั้งระบบประชามติ

สรุปสถาปัตยกรรม ข้อมูลตาราง ขั้นตอนการใช้งานของลูกบ้านและผู้ดูแลระบบ PS33 Home System

1. ภาพรวมระบบ (System Overview)

ระบบประชามติ (Voting System) พัฒนาขึ้นเพื่อช่วยให้นิติกรรมหมู่บ้านของโครงการ **PS33** สามารถสอบถามความคิดเห็น โหวตลงคะแนนเสียง หรือรับฟังความคิดเห็นจากลูกบ้านได้อย่างโปร่งใส สะดวก และปลอดภัย ผ่านทางแอปพลิเคชัน LINE OA (LINE Front-end Framework - LIFF)

กฎกติกาหลัก: จำกัดการใช้สิทธิ์โหวตได้เพียง **1 สิทธิ์ต่อ 1 บ้านเลขที่** ในแต่ละหัวข้อโหวต เพื่อป้องกันความซ้ำซ้อนและรักษาความเที่ยงตรงของคะแนนเสียง

2. สถาปัตยกรรมตารางข้อมูล (Database Architecture)

โครงสร้างฐานข้อมูล MySQL ที่ใช้จัดเก็บข้อมูลมีตารางหลักที่ทำงานสัมพันธ์กัน 3 ตารางดังนี้:

ชื่อตาราง คอลัมน์สำคัญ บทบาทหน้าที่
ims_vote_topic topic_id, title, description, status เก็บหัวข้อการโหวตหลักที่ตั้งขึ้นโดยนิติบุคคล
ims_vote_option option_id, topic_id, option_text เก็บข้อความตัวเลือกย่อยของแต่ละหัวข้อโหวต (ไม่จำกัดจำนวนตัวเลือก)
ims_vote_record vote_id, topic_id, house_number, option_id, voted_at เก็บประวัติการลงประชามติ โดยกำหนดค่า UNIQUE KEY(topic_id, house_number) เพื่อบังคับสิทธิ์ 1 สิทธิ์โหวตต่อบ้านเลขที่ในระดับ Database

ตารางสัมพันธ์กับตารางผูก LINE หลักของลูกบ้าน: ระบบจะดึงข้อมูลบ้านเลขที่จากตาราง ims_house_line_user ของโครงการเพื่อยืนยันตัวตนก่อนโหวต

3. ขั้นตอนการตั้งค่าหัวข้อสำหรับนิติบุคคล (Admin Workflow)

นิติบุคคลสามารถจัดการโหวตได้ผ่านหน้าจอแผงควบคุมหลัก โดยทำตามขั้นตอนดังนี้:

1 เข้าใช้งานเมนูระบบประชามติ

ล็อกอินเข้าสู่ระบบหลังบ้านของผู้ดูแลระบบ จากนั้นไปที่เมนู **"ระบบประชามติ (Voting) -> ตั้งค่าหัวข้อโหวต"** หรือเข้าใช้งานโดยตรงที่ไฟล์ manage_vote.php

2 สร้างหัวข้อและกำหนดตัวเลือก

กดปุ่ม "เพิ่มหัวข้อใหม่" เพื่อเปิดหน้าต่างสร้างโหวต จากนั้นกรอกหัวข้อ รายละเอียด และกดเพิ่มตัวเลือกได้ไม่จำกัดจำนวน (ต้องกรอกอย่างน้อย 2 ตัวเลือกขึ้นไป) จากนั้นกดบันทึกเพื่อเปิดรับโหวต

3 ควบคุมสถานะการโหวต

ในตารางจัดการหลัก นิติบุคคลสามารถกดปุ่ม "ปิดโหวต" หรือ "เปิดโหวต" เพื่อควบคุมการเปิดรับความคิดเห็นของลูกบ้านได้ตลอดเวลา หรือกดลบหัวข้อหากไม่ต้องการใช้งานแล้ว

4 ดูรายงานผลและประวัติ

กดปุ่ม "รายงานผล" บนแถวหัวข้อเพื่อดูสถิติคะแนนเสียง โดยแสดงผลเป็นกราฟแท่งแบ่งสัดส่วนเปอร์เซ็นต์อย่างชัดเจน พร้อมมีตารางประวัติผู้ร่วมลงมติแยกตามบ้านเลขที่เพื่อความโปร่งใส (Audit Log)

4. ขั้นตอนการลงมติสำหรับลูกบ้าน (Voter LIFF Workflow)

เมื่อลูกบ้านกดเข้าเมนู "โหวตประชามติ" จาก LINE OA ของหมู่บ้าน (ลิงก์ไปยังหน้าจอ line_oa/house/vote.php):

1 ยืนยันตัวตนอัตโนมัติ (LIFF Verification)

ระบบจะเรียกใช้งาน LINE LIFF SDK เพื่อดึงโปรไฟล์ LINE User ID ขึ้นมาตรวจสอบกับตารางทะเบียนลูกบ้าน ims_house_line_user หลังบ้านทันที

2 ล็อกเลขที่บ้าน (Readonly Lock)

หากลูกบ้านเคยลงทะเบียนผูกบัญชี LINE ไว้แล้ว ระบบจะดึงค่าบ้านเลขที่ของลูกบ้านขึ้นมาแสดงในแถบข้อมูลส่วนบุคคล พร้อม **ล็อกช่องบ้านเลขที่และปิดช่องแก้ไข** เพื่อไม่ให้ผู้ใช้งานเปลี่ยนบ้านเลขที่โหวตแทนบ้านอื่น

3 เลือกหัวข้อและตรวจสอบสิทธิ์ซ้ำซ้อน

ลูกบ้านเลือกหัวข้อที่ต้องการโหวต ทันทีที่เลือกหัวข้อ ระบบจะส่งการตรวจสอบ (AJAX) ไปยัง API เพื่อสืบค้นว่าบ้านเลขที่นี้เคยลงคะแนนในหัวข้อนี้ไปแล้วหรือไม่

  • หากยังไม่เคยโหวต: ระบบจะเปิดสิทธิ์ให้ลูกบ้านเลือกคำตอบและกดปุ่ม "ส่งคะแนนโหวต" ได้ตามปกติ
  • หากเคยโหวตไปแล้ว: ระบบจะแสดงการแจ้งเตือนแถบสีแดงชี้แจงวันเวลาที่โหวต พร้อมระบุคำตอบที่เคยเลือกไว้ และปิดกั้นปุ่มกดส่งโหวต

4 บันทึกและส่งข้อความแจ้งเตือน

เมื่อกดส่งสำเร็จ ข้อมูลประวัติการโหวตจะถูกเก็บลงตาราง ims_vote_record และหน้าจอ LIFF จะทำการปิดตัวลงอัตโนมัติ

5. มาตรการความปลอดภัยและการป้องกันสวมสิทธิ์

  • Server-side Cross Validation: เมื่อลูกบ้านกดส่งโหวต API ฝั่งเซิร์ฟเวอร์ (vote_submit_api.php) จะดึงประวัติการลงทะเบียนของ LINE User ID นั้นมาเทียบกับค่าบ้านเลขที่ที่ส่งมาอีกครั้ง เพื่อป้องกันการดัดแปลง Payload ผ่านเบราว์เซอร์
  • Database Constraint: ตาราง ims_vote_record มีการสร้าง Unique Constraint ครอบคลุมสองคีย์หลัก ทำให้มั่นใจได้ว่าจะไม่มีค่าซ้ำเกิดขึ้นในระดับโครงสร้างข้อมูล
  • User Validation Protection: หากผู้ใช้คนใดนำลิงก์ไปเปิดนอกระบบ LINE หรือไม่มีประวัติการลงทะเบียน ทะเบียนบ้านจะไม่มีสิทธิ์ร่วมโหวตเด็ดขาด ระบบจะบล็อกและแสดงคำแนะนำให้ลงทะเบียนก่อน
