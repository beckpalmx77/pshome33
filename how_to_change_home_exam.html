กรณีศึกษาการย้ายบ้านภายในโครงการ (Case Study)

ข้อมูลลูกบ้าน: คุณศิริวรรณ ลุนลี (เบอร์โทรศัพท์: 091-1349494)
การเปลี่ยนแปลง: ย้ายที่อยู่อาศัยภายในโครงการจากบ้านเลขที่ 67/175 ไปยังบ้านเลขที่ 67/180

ในการดำเนินการกรณีดังกล่าว เพื่อรักษาความถูกต้องของข้อมูลนิติบุคคล ทะเบียนรถยนต์ สิทธิ์บัญชี LINE OA และประวัติการเงิน ต้องแบ่งการดำเนินงานออกเป็น 2 ส่วนหลัก คือขั้นตอนสำหรับ เจ้าหน้าที่นิติบุคคล และรายละเอียดการเขียนคำสั่ง/อัปเดตข้อมูลของ โปรแกรมเมอร์/ระบบฐานข้อมูล

1. ขั้นตอนปฏิบัติสำหรับเจ้าหน้าที่นิติบุคคล (Juristic Workflow)

  1. ขั้นตอนที่ 1: เคลียร์ข้อมูลที่บ้านเลขที่เดิม (67/175)
    เจ้าหน้าที่เปิดเมนูระบบ ไปที่หน้าจอ เปลี่ยนสิทธิ์ผู้อยู่อาศัย เลือกบ้านเลขที่ 67/175 จากนั้นเลือกประเภทรายการ "ย้ายออก/เข้า" และติ๊กเลือก Checklist เพื่อระงับสิทธิ์ผู้ใช้งานเดิม, ปลดล็อกการผูก LINE OA ของผู้เช่าเดิม, และสั่งยกเลิกสติกเกอร์/ข้อมูลรถยนต์ของบ้านเลขที่นี้ทั้งหมด
  2. ขั้นตอนที่ 2: บันทึกข้อมูลที่บ้านเลขที่ใหม่ (67/180)
    ที่หน้าจอจัดการข้อมูลบ้าน ค้นหาบ้านเลขที่ 67/180 (หากไม่มีประวัติ ให้เพิ่มทะเบียนบ้านใหม่เข้าระบบก่อน) จากนั้นทำการระบุชื่อผู้ติดต่อคนใหม่เป็น "ศิริวรรณ ลุนลี" เบอร์โทรศัพท์ "0911349494" และโอนย้ายข้อมูลรถยนต์ที่เธอนำมาด้วยไปกรอกที่ข้อมูลบ้านใหม่นี้
  3. ขั้นตอนที่ 3: แนะนำให้ลูกบ้านเปิดแอปพลิเคชัน LINE OA อีกครั้ง
    เนื่องจากระบบตัดสิทธิ์ LINE ของบ้านเก่าออกแล้ว เมื่อคุณศิริวรรณเปิด LINE OA พฤกษา 33 ระบบจะตรวจพบว่าสิทธิ์การผูกเดิมถูกยกเลิก และจะขอให้เธอกรอกเบอร์โทรศัพท์ 091-1349494 ใหม่เพื่อรับ OTP เมื่อยื่นเสร็จ บัญชี LINE ของเธอจะถูกดึงไปเชื่อมโยงกับบ้านเลขที่ 67/180 อัตโนมัติทันที

3. คำสั่ง SQL ที่ใช้ในการรันคำสั่งเบื้องหลัง (SQL Commands Execution)

คำสั่ง SQL ที่ต้องนำไปประมวลผลจริงในระบบฐานข้อมูลตามลำดับการทำงาน (เรียงตามกฎ Transaction):

A. การปิดสิทธิ์และล้างข้อมูลที่บ้านเลขที่เดิม (67/175)

UPDATE ims_house 
SET contact_name = '', 
    phone_number = '', 
    car_no1 = '', car_no2 = '', car_no3 = '', car_no4 = '',
    sticker_receive_status = 'N',
    remark = 'ย้ายออกไปบ้านเลขที่ 67/180'
WHERE house_number = '67/175';

UPDATE ims_house_line_user 
SET status = 'N' 
WHERE house_number = '67/175' AND line_phone = '0911349494';

UPDATE ims_house_pet 
SET remark = 'ย้ายออกจากการปรับปรุงสิทธิ์ไป 67/180'
WHERE house_number = '67/175';
