ระบบจัดการการเปลี่ยนย้ายข้อมูลบ้านและบัญชีผู้ใช้งาน

เอกสารการออกแบบแนวคิด ขั้นตอน วิธีการพัฒนา และระบบจัดการความเชื่อมโยงบัญชีผู้ใช้แบบโต้ตอบ

1. แนวคิดและการเชื่อมโยงข้อมูลระบบ (System Mapping Concept)

การเปลี่ยนสิทธิ์หรือผู้อยู่อาศัยในบ้านเลขที่หนึ่งๆ จำเป็นต้องจัดการข้อมูลบัญชีผู้ใช้ระบบ (Web Account) และส่วนย่อยอื่นๆ เพื่อป้องกันช่องโหว่ด้านความปลอดภัยและการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต โดยระบบมีการจัดโครงสร้างและการเชื่อมโยงข้อมูลดังนี้:

โครงสร้างการเชื่อมโยงบัญชีผู้ใช้งาน (User Account Integration)
  • บัญชีผู้ใช้หน้าเว็บ (ims_user): ลงทะเบียนและเข้าใช้งานโดยใช้ "หมายเลขโทรศัพท์" เป็นชื่อผู้ใช้ (user_id / email) เพื่อเข้าเช็คข้อมูลการเงินหรือยื่นคำร้อง
  • บัญชี LINE OA (ims_house_line_user): เชื่อมโยงบัญชีผู้ใช้เว็บกับระบบ LINE โดยมีคีย์เชื่อมโยงคือ line_phone (เบอร์โทรศัพท์) ร่วมกับ house_number (บ้านเลขที่)
  • การแสดงผลข้อมูลแบบรวม (Unified View): ระบบใช้ View v_ims_user ในการผสานบัญชีผู้ใช้หน้าเว็บและโปรไฟล์ไลน์ หากมีการยกเลิก LINE หรือเบอร์โทร ข้อมูลความเชื่อมโยงจะหลุดออกทันที
วิเคราะห์การเปลี่ยนข้อมูลและบัญชีผู้ใช้ที่เกี่ยวข้อง
กรณีการดำเนินงาน การจัดการบัญชีผู้ใช้ (ims_user) การจัดการบัญชี LINE OA (ims_house_line_user) ส่วนย่อยอื่นๆ ที่เกี่ยวข้อง
1. ลูกบ้านย้ายบ้านออก
(ย้ายออกจากหมู่บ้าน / ขายบ้าน)		 ระงับการใช้งาน (Inactive)
ของผู้อยู่อาศัยทุกคนที่ผูกกับเบอร์โทรของบ้านนี้ 		ยกเลิกสิทธิ์ (Status = 'N')
ตัดการเชื่อมโยงทุก LINE ID ที่ผูกกับบ้านนี้ 		- ยกเลิกทะเบียนรถยนต์สะสม
- ระงับประวัติการลงทะเบียนสัตว์เลี้ยง
- ลบประวัติสิทธิ์การลงคะแนนประชุม (Meeting Vote)
2. เปลี่ยนผู้เช่า (Change Tenant)
(ผู้เช่าเดิมย้ายออก ผู้เช่าใหม่ย้ายเข้า)		 ระงับเฉพาะบัญชีผู้เช่าเดิม
(โทรศัพท์ผู้เช่าเดิม) แต่คงเหลือบัญชีของเจ้าของบ้านไว้ 		ยกเลิก LINE ของผู้เช่าเดิม
คงสถานะ LINE ของเจ้าของบ้านไว้รับยอดหนี้ค่าส่วนกลาง 		- ลบทะเบียนรถและสติกเกอร์ผู้เช่าเดิม
- ระงับประวัติสัตว์เลี้ยงผู้เช่าเดิม
- ประวัติการแจ้งซ่อม (Job) เก่าคงไว้แต่ตัดสิทธิ์เรียกดู
3. เปลี่ยนเจ้าของบ้าน (Change Owner)
(ขายเปลี่ยนมือโอนกรรมสิทธิ์)		 ระงับบัญชีเจ้าของเดิม & ผู้เช่าเดิม
สลับบัญชีผู้ใช้ใหม่โดยลงทะเบียนเบอร์เจ้าของใหม่ 		ล้างสิทธิ์ LINE ทั้งหมดของบ้าน
เพื่อความปลอดภัยของข้อมูลเจ้าของคนใหม่ 		- ตรวจสอบยอดหนี้ค้างชำระ (ต้องเป็น 0 เท่านั้น)
- ลบทะเบียนรถและสัตว์เลี้ยงทั้งหมด
- การลงคะแนนเสียงประชุมใหญ่สลับไปให้เจ้าของใหม่
ส่วนอื่นๆ ที่เกี่ยวข้องที่ต้องจัดระเบียบข้อมูล
สติกเกอร์จอดรถ (ims_sticker_received_list)

สติกเกอร์และสิทธิ์ผ่านเข้า-ออกเดิมที่เคยออกให้ทะเบียนรถเก่าของลูกบ้านเดิมที่ย้ายออก จะต้องถูกระงับสิทธิ์ในระบบและตั้งสถานะยกเลิก (Status = 'N') เพื่อป้อนข้อมูลรถยนต์ของผู้พักอาศัยรายใหม่และออกสติกเกอร์ชุดใหม่

การประชุมหมู่บ้าน (ims_register_meeting)

ระบบสิทธิ์โหวตและลงทะเบียนเข้าประชุมจะยึดตามความเป็นเจ้าของและผู้อยู่อาศัยปัจจุบัน เมื่อเจ้าของเปลี่ยน สิทธิ์ในการออกเสียงและประวัติการลงทะเบียนที่กำลังมีผลการประชุมรอบใหม่จะย้ายไปที่ข้อมูลติดต่อชุดใหม่ทันที

รายการแจ้งซ่อมบำรุง (jobrecord / ims_job_record)

ประวัติการแจ้งซ่อมแซมสิ่งอำนวยความสะดวกในอดีตจะถูกคงไว้เพื่อประวัติของตัวบ้าน แต่รายละเอียดผู้แจ้งจะถูกย้ายเข้าระบบประวัติเก่า แอดมินและลูกบ้านคนใหม่จะไม่เห็นชื่อผู้รับผิดชอบเดิมเพื่อปกป้องข้อมูลส่วนบุคคล (PDPA)

ประวัติการเข้าสู่ระบบ (ims_user_login_logs)

เพื่อความปลอดภัย เมื่อบัญชีผู้ใช้ถูกเปลี่ยนสถานะเป็น Inactive หรือยกเลิกการผูกสิทธิ์ ระบบจะต้องสั่งการล้าง Session ในตารางล็อกการเข้าสู่ระบบและบังคับให้ทุกอุปกรณ์ทำรายการ Logout ออกทันที

2. ขั้นตอนการดำเนินงานบนหน้าจอและบัญชีผู้ใช้

ขั้นตอนการจัดการข้อมูลบ้านและบัญชีผู้ใช้อย่างถูกต้องสำหรับเจ้าหน้าที่นิติบุคคล:

1 ค้นหาและตรวจสอบประวัติบัญชี (Account Audit)

แอดมินป้อนเลขที่บ้าน ระบบจะแสดงชื่อลูกบ้านปัจจุบันพร้อมรายชื่อบัญชีผู้ใช้งานหน้าเว็บ (ims_user) และรายการ LINE OA ที่เชื่อมอยู่ รวมถึงสถานะบัญชีการใช้งานในปัจจุบัน

2 เลือกรูปแบบการย้ายและประมวลผลสิทธิ์ (Processing Sinks)

แอดมินระบุรูปแบบการย้าย ระบบจะวิเคราะห์อัตโนมัติว่าต้องการระงับบัญชีผู้ใช้ (Web Account) หมายเลขใดบ้าง และบัญชี LINE บัญชีใดต้องทำลายโทเคนการรับแจ้งเตือน

3 ปรับโครงสร้างข้อมูลทางการเงินคงค้าง (Settle Balances)

ระบบตรวจสอบประวัติค้างชำระและรายการผ่อนชำระค้างส่ง (Installments) ในกรณีขายเปลี่ยนเจ้าของบ้าน หากมียอดค้างชำระ แอดมินต้องทำรายการรับเงินโอนหรือปรับยอดหนี้เป็นศูนย์ให้เรียบร้อยก่อนเพื่อไม่ให้เกิดการสับสนกับเจ้าของใหม่

4 ป้อนข้อมูลลูกบ้านคนใหม่และสร้างบัญชี (Insert & Provisioning)

กรอกข้อมูลผู้ติดต่อหลัก เบอร์โทรศัพท์ และเลขทะเบียนรถยนต์ใหม่ ในขั้นตอนนี้ระบบจะเปิดตัวเลือก "สร้างบัญชีผู้ใช้เว็บใหม่โดยอัตโนมัติ" ตามหมายเลขเบอร์โทรศัพท์ที่ป้อนเข้ามาใหม่

5 ตรวจสอบความถูกต้องและส่งสิทธิ์ลงทะเบียน (Security Handover)

เมื่อบันทึกข้อมูลเรียบร้อย ระบบจะแจ้งเตือนการล้าง Session เก่าเสร็จสิ้น และมีหน้าจอป๊อปอัปให้ส่ง QR Code ลงทะเบียนสิทธิ์ LINE OA ให้แก่ผู้อยู่อาศัยใหม่สแกนเพื่อผูกข้อมูลบัญชีทันที

3. วิธีการทางเทคนิค & SQL สำหรับจัดการบัญชีและส่วนเชื่อมโยง
1. SQL จัดการบัญชีผู้ใช้และทำลายล้างการเข้าสู่ระบบเก่า (Web Account & Session Termination)

เมื่อลูกบ้านย้ายออก การระงับสิทธิ์บัญชีผู้ใช้หน้าเว็บ (ims_user) และล้างประวัติเซสชันเข้าใช้งานสามารถจัดการด้วยชุดสคริปต์นี้:

-- 1. ค้นหาเบอร์โทรศัพท์ (ซึ่งใช้เป็น User ID) ของผู้อยู่อาศัยเดิมที่ต้องระงับสิทธิ์
-- ยกตัวอย่างการระงับสิทธิ์กรณีลูกบ้านเดิมย้ายออก
UPDATE ims_user SET 
    status = 'Inactive',
    role = 'inactive_resident',
    update_date = NOW()
WHERE user_id = (
    SELECT phone_number FROM ims_house WHERE house_number = :house_number
);

-- 2. ทำลายประวัติหรือล้าง Session การเข้าระบบเพื่อบังคับ Logout ในอุปกรณ์ทั้งหมด
DELETE FROM ims_user_login_logs 
WHERE user_id = (
    SELECT phone_number FROM ims_house WHERE house_number = :house_number
);
2. SQL จัดการส่วนเกี่ยวข้อง (สัตว์เลี้ยง สติกเกอร์รถ และประวัติการประชุม)

ระบบต้องอัปเดตสถานะของส่วนย่อยอื่นๆ เพื่อป้องกันประวัติซ้ำซ้อนกับลูกบ้านรายใหม่:

-- 1. ระงับรายการสติกเกอร์ที่ผูกกับรถและบ้านเลขที่เดิม
UPDATE ims_sticker_received_list SET 
    status = 'N', 
    remark = CONCAT('ยกเลิกสิทธิ์เนื่องจากเปลี่ยนข้อมูลผู้อยู่อาศัยเมื่อ ', NOW())
WHERE house_number = :house_number;

-- 1. ย้ายสถานะสัตว์เลี้ยงของผู้อยู่อาศัยเดิมให้เป็นยกเลิก (เพื่อความสะอาดของทะเบียนรายหลัง)
UPDATE ims_pet_record SET 
    status = 'N', 
    remark = 'ลูกบ้านเดิมย้ายออก' 
WHERE house_number = :house_number;

-- 1. ลบรายการลงชื่อจองเข้าร่วมประชุมหรือโหวตที่ล่วงหน้าของเจ้าของเดิม (หากรอบการประชุมยังไม่เกิดขึ้นจริง)
DELETE FROM ims_register_meeting 
WHERE house_number = :house_number AND meeting_status = 'PENDING';
3. PHP Controller ที่สมบูรณ์พร้อมระบบจัดการบัญชีและ Audit Log

นำไปปรับใช้ใน Controller หลักเพื่อรักษาความปลอดภัยระดับ Database Level:

if ($_POST["action"] === 'CHANGE_HOUSE_HOLDER_FULL') {
    $house_number = $_POST["house_number"];
    $change_type = $_POST["change_type"];
    $new_name = $_POST["new_contact_name"];
    $new_phone = $_POST["new_phone_number"];
    $new_status = $_POST["new_house_status"];
    $car1 = $_POST["car_no1"] ?? '';
    $remark = $_POST["remark"] ?? '';
    
    // สถานะระงับบัญชีผู้ใช้เก่า
    $deactivate_old_user = isset($_POST["deactivate_old_user"]) ? true : false;
    $admin_name = $_SESSION['first_name'] . " " . $_SESSION['last_name'];

    try {
        $conn->beginTransaction();

        // ดึงข้อมูลลูกบ้านเดิมก่อนแก้ไขเพื่อเขียน Log และระงับบัญชีเว็บ
        $stmt_old = $conn->prepare("SELECT contact_name, phone_number, house_status FROM ims_house WHERE house_number = :house_number");
        $stmt_old->execute([':house_number' => $house_number]);
        $old_data = $stmt_old->fetch(PDO::FETCH_ASSOC);

        if ($old_data) {
            $old_phone = $old_data['phone_number'];
            
            // 1. ระงับการใช้งานบัญชีผู้ใช้เก่า (ims_user)
            if ($deactivate_old_user && !empty($old_phone)) {
                $stmt_deact = $conn->prepare("UPDATE ims_user SET status = 'Inactive' WHERE user_id = :old_phone");
                $stmt_deact->execute([':old_phone' => $old_phone]);

                // ล้าง Login Session บังคับ Logout
                $stmt_sess = $conn->prepare("DELETE FROM ims_user_login_logs WHERE user_id = :old_phone");
                $stmt_sess.execute([':old_phone' => $old_phone]);
            }
        }

        // 2. บันทึก Log การย้ายข้อมูล
        $log_sql = "INSERT INTO ims_house_change_log (house_number, change_type, old_contact_name, old_phone_number, old_house_status, new_contact_name, new_phone_number, new_house_status, remark, created_by)
                    VALUES (:house_number, :change_type, :old_name, :old_phone, :old_status, :new_name, :new_phone, :new_status, :remark, :admin_name)";
        $stmt_log = $conn->prepare($log_sql);
        $stmt_log->execute([
            ':house_number' => $house_number,
            ':change_type' => $change_type,
            ':old_name' => $old_data['contact_name'] ?? '',
            ':old_phone' => $old_phone ?? '',
            ':old_status' => $old_data['house_status'] ?? '',
            ':new_name' => $new_name,
            ':new_phone' => $new_phone,
            ':new_status' => $new_status,
            ':remark' => $remark,
            ':admin_name' => $admin_name
        ]);

        // 3. ปรับปรุงข้อมูลบ้าน
        $update_sql = "UPDATE ims_house SET 
                        contact_name = :new_name,
                        phone_number = :new_phone,
                        house_status = :new_status,
                        car_no1 = :car1, car_no2 = '', car_no3 = '', car_no4 = '', car_no5 = '',
                        remark = :remark,
                        update_by = :admin_name
                       WHERE house_number = :house_number";
        $stmt_update = $conn->prepare($update_sql);
        $stmt_update->execute([
            ':new_name' => $new_name,
            ':new_phone' => $new_phone,
            ':new_status' => $new_status,
            ':car1' => $car1,
            ':remark' => $remark,
            ':admin_name' => $admin_name,
            ':house_number' => $house_number
        ]);

        // 4. จัดการสิทธิ์การผูก LINE
        if ($change_type === 'CHANGE_OWNER' || $change_type === 'MOVE_OUT_IN') {
            $line_sql = "UPDATE ims_house_line_user SET status = 'N' WHERE house_number = :house_number";
            $stmt_line = $conn->prepare($line_sql);
            $stmt_line->execute([':house_number' => $house_number]);
        } else if ($change_type === 'CHANGE_TENANT') {
            $line_sql = "UPDATE ims_house_line_user SET status = 'N' WHERE house_number = :house_number AND user_type IN ('Tenant', 'Resident')";
            $stmt_line = $conn->prepare($line_sql);
            $stmt_line->execute([':house_number' => $house_number]);
        }

        $conn->commit();
        echo json_encode(["status" => "success", "message" => "ดำเนินการเปลี่ยนสิทธิ์ข้อมูลและเคลียร์บัญชีเสร็จสิ้น"]);

    } catch (Exception $e) {
        $conn->rollBack();
        echo json_encode(["status" => "error", "message" => "ข้อผิดพลาดระบบ: " . $e->getMessage()]);
    }
}
