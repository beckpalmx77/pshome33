Deployment Guide

คู่มือการติดตั้งระบบ TutorMatch AI

ขั้นตอนการจัดเตรียมเครื่องคอมพิวเตอร์เพื่อเปิดรันระบบ FastAPI หลังบ้านและระบบวิเคราะห์ AI ออฟไลน์

📋

1. สิ่งที่ต้องเตรียมความพร้อม (System Requirements)

  • ✔️ **Python:** เวอร์ชัน 3.10 ขึ้นไป (ผ่านการทดสอบและทำงานได้สมบูรณ์บน Python 3.14.3)
  • ✔️ **ความสามารถของอุปกรณ์:** เว็บแคม (Webcam) ที่สามารถสตรีมภาพและบันทึกภาพถ่ายบนเว็บบราวเซอร์ได้
  • ✔️ **ฐานข้อมูล:** ระบบใช้ SQLite ในการพัฒนา ทำให้ไม่ต้องลงโปรแกรมฐานข้อมูลแยก
  • ✔️ **อินเทอร์เน็ต:** จำเป็นในการดาวน์โหลดชุดไลบรารีและดาวน์โหลดฟอนต์ภาษาไทยในการรันครั้งแรก
🔧

2. ขั้นตอนการติดตั้งโปรแกรม (Installation Steps)

📍 ขั้นตอนที่ 1: สร้างและเปิดใช้งาน Virtual Environment (แนะนำ)
สร้างสภาพแวดล้อมจำลองของ Python เพื่อป้องกันไม่ให้เวอร์ชันไลบรารีปะปนกับโครงการอื่น
# เปิด PowerShell หรือ Terminal ในโฟลเดอร์โครงการ (D:\wk_ai\tutor_match)
python -m venv venv

# สำหรับ Windows (PowerShell) เพื่อเปิดรันใช้งาน
.\venv\Scripts\activate
📍 ขั้นตอนที่ 2: ติดตั้งไลบรารีที่จำเป็นผ่าน PIP
รันคำสั่งติดตั้งแพ็กเกจระบบเว็บ FastAPI และฟังก์ชันด้านปัญญาประดิษฐ์ (AI / Image / NLP)
pip install fastapi uvicorn opencv-python opencv-contrib-python sqlalchemy jinja2 pythainlp requests reportlab pydantic
📍 ขั้นตอนที่ 3: ตรวจสอบความสมบูรณ์ของโครงสร้างโฟลเดอร์
ตรวจสอบไฟล์โปรแกรมทั้งหมดให้อยู่ในตรรกะโฟลเดอร์ดังต่อไปนี้:
ชื่อไฟล์ / โฟลเดอร์ หน้าที่การทำงาน
main.py ตัวเชื่อม Gateway API ของ FastAPI และ Endpoint หลัก
models.py SQLAlchemy Database Schema ตารางข้อมูลสแกนหน้าและติวเตอร์
database.py การเชื่อมต่อและการกำหนด session ของ SQLite
schemas.py Pydantic Data validation schemas
ai_engine.py อัลกอริทึมวิเคราะห์สแกนหน้า (LBPH) และจับคู่ (Thai NLP TF-IDF)
static/index.html หน้าจอหลัก LIFF Portal Simulator (หน้าบ้านดึงข้อมูล)
⚡

3. การเปิดสั่งรันระบบเซิร์ฟเวอร์ (Running Backend)

รันคำสั่งด้านล่างเพื่อเปิดการทำงานเว็บแอปพลิเคชันหลังบ้าน ซึ่งจะทำหน้าที่สร้างฐานข้อมูล `tutor_match.db` ขึ้นมาอัตโนมัติในการรันครั้งแรก: 

python -m uvicorn main:app --host 127.0.0.1 --port 8000

เมื่อระบบเริ่มเปิดตัวและแสดงข้อความ "Uvicorn running on http://127.0.0.1:8000" ให้เข้าไปหน้าบราวเซอร์แล้วเปิด: 

http://127.0.0.1:8000
💡
คำเตือนเรื่อง Windows Path Warning:
หากเรียกใช้คำสั่ง `uvicorn main:app` ตรงๆ แล้วแจ้งว่าไม่รู้จักโปรแกรม (Command Not Found) ให้เรียกใช้งานผ่านตัวรันโมดูลของไพทอน `python -m uvicorn` เสมอ เพื่อข้ามข้อจำกัดของ Windows environment variable PATH
💬

4. การนำไปประยุกต์ใช้งานและเชื่อมต่อ LINE OA & LIFF

เมื่อทดสอบการทำงานจนพอใจแล้ว หากต้องการเชื่อมต่อเข้าสู่บัญชี LINE OA เพื่อเปิดใช้งานจริง ให้ทำตามแนวทางปฏิบัติตามคู่มือ LINE Developers ด้านล่างนี้:

🔗 1. แปลงโปรเจกต์ให้เป็น HTTPS
เนื่องจากระบบ Webhook และ LIFF ของ LINE บังคับการส่งข้อมูลผ่าน **HTTPS (SSL)** ที่มีความปลอดภัยสูงสุดเท่านั้น สำหรับการเชื่อมต่อทดลองรันจากเครื่องบ้าน สามารถใช้เครื่องมือ **ngrok** เพื่ออุโมงค์พอร์ต 8000 ของ FastAPI ให้ออกมาเป็นที่อยู่สาธารณะ HTTPS: 
ngrok http 8000
💬 2. ตั้งค่า LINE Webhook
- เข้าไปที่ [LINE Developers Console](https://developers.line.biz)
- สร้าง Messaging API Channel และนำ URL HTTPS จาก ngrok ไปกรอกในเมนู **Webhook URL** (เช่น `https://xxxx.ngrok-free.app/webhook`)
📱 3. สร้างแอปพลิเคชัน LINE LIFF
- ภายใต้ Provider เดียวกัน กดสร้างแอปย่อยประเภท **LIFF**
- ในช่อง **Endpoint URL** ให้กรอกที่อยู่เว็บหลังบ้านไปยังหน้า static (เช่น `https://xxxx.ngrok-free.app/static/index.html`)
⚠️
ข้อสำคัญด้านสิทธิ์การใช้กล้อง (Camera Access):
ต้องไปที่แท็บ LIFF App settings ใน LINE Developers แล้วกดยื่นคำขอเปิดสิทธิ์ใช้งาน **Camera / Microphone Access** เสมอ เพื่อให้เบราว์เซอร์ของห้องแชทไลน์อนุญาตให้ผู้ใช้ถ่ายรูปสแกนหน้าได้
