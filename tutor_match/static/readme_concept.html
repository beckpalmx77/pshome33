ที่มาและแนวคิดของโครงการ (Project Concept)

TutorMatch AI ถูกออกแบบขึ้นเพื่อแก้ปัญหาความยุ่งยากในการค้นหาผู้สอน (Tutor) ที่ตรงกับสไตล์การเรียน ความรู้พื้นฐาน งบประมาณ และเวลาของนักเรียน โดยการผสานสองเทคโนโลยีที่ทรงพลังเข้าด้วยกัน:

  • LINE Official Account & LINE LIFF: เป็นช่องทางหลักที่อำนวยความสะดวกให้ผู้ใช้งานสามารถเข้าถึงระบบได้ทันทีโดยไม่ต้องติดตั้งแอปพลิเคชันเพิ่มเติม
  • Artificial Intelligence (AI): ใช้ในการตรวจสอบความปลอดภัย (ยืนยันตัวตนด้วยใบหน้า) และประมวลผลวิเคราะห์ข้อมูลเพื่อทำนายและแนะนำติวเตอร์ที่เหมาะสมที่สุด (Tutor Matching Engine)
👤

ระบบการลงทะเบียนและการยืนยันตัวตน

เพื่อความปลอดภัยและความน่าเชื่อถือของแพลตฟอร์ม ทั้งผู้เรียนและติวเตอร์จะต้องผ่านระบบยืนยันตัวตนด้วยใบหน้า:

  • การสมัครสมาชิก: ผู้ใช้งานบันทึกข้อมูลส่วนตัว ประวัติ และถ่ายรูปใบหน้าเก็บไว้เปรียบเทียบในฐานข้อมูล
  • การเข้าใช้งาน (Login / Verification): เมื่อจะเข้าใช้งานระบบสแกนใบหน้าผ่านกล้องบน LINE LIFF เพื่อจับคู่พิกัดของใบหน้ากับฐานข้อมูล เป็นการเพิ่มความปลอดภัยและความมั่นใจให้กับผู้เรียน
🎯

ระบบวิเคราะห์ความถนัดและการจับคู่ติวเตอร์

ระบบการจับคู่ที่มีประสิทธิภาพสูงกว่าการค้นหาด้วย Keyword แบบเดิม โดยใช้หลักการ AI ประเมินผล:

  • ข้อมูลติวเตอร์: ประวัติ, วิชาที่สอน, ระดับชั้น, ความถนัดเฉพาะตัว, ระดับราคา, สไตล์การสอน (เช่น เน้นสนุกสนาน, เน้นสอบแข่งขัน, เน้นเข้าใจพื้นฐาน)
  • ข้อมูลความต้องการผู้เรียน: วิชาที่ต้องการเรียน, คะแนนเป้าหมาย, งบประมาณ, สไตล์การเรียนที่ชอบ, ข้อความอธิบายความคาดหวัง
  • AI Engine: ทำการคำนวณและวิเคราะห์ความเข้ากันได้แบบหลายมิติและแสดงผลลัพธ์เป็นคะแนนความเหมาะสม (Matching Score)

ชุดเทคโนโลยีที่เลือกใช้ (Technology Stack)

Backend & UI Integration

  • Python 3.10+: ภาษาหลักในการพัฒนาระบบหลังบ้านและเขียนโมเดล AI
  • FastAPI: Web Framework ของ Python ที่ทำงานได้เร็วมาก (Asynchronous) รองรับ OpenAPI auto-doc
  • LINE Messaging API SDK: ไลบรารีควบคุมการส่งและรับข้อความใน LINE
  • LINE LIFF (LINE Front-end Framework): ใช้สร้างหน้าเว็บแอปย่อยๆ ฝังใน LINE สำหรับหน้าจอลงทะเบียน ค้นหาติวเตอร์ และสแกนกล้อง

AI / Database & Tools

  • DeepFace / OpenCV / MediaPipe: ไลบรารี Python สำหรับจับใบหน้า (Face Detection) และแปลงใบหน้าเป็น Embedded Vector เพื่อเปรียบเทียบในระบบ Face Recognition
  • Sentence-Transformers (HuggingFace) / Gemini API: แปลงข้อความความถนัดของติวเตอร์และความต้องการของผู้เรียนเป็นเวกเตอร์ หรือใช้ Generative AI วิเคราะห์จับคู่เชิงความหมาย
  • PostgreSQL + pgvector: ฐานข้อมูลหลักที่รองรับการเก็บรูปภาพเวกเตอร์สำหรับสแกนใบหน้าและข้อมูลประวัติติวเตอร์

โมดูลปัญญาประดิษฐ์ (AI Engine Logic)

ระบบ AI แบ่งการทำงานออกเป็นสองส่วนหลักอย่างชัดเจน:

📸

1. การยืนยันตัวตนด้วยใบหน้า (Face Verification)

ระบบจะใช้แนวคิด Face Recognition Metric Learning ในการเปรียบเทียบ:

  1. สแกนกล้องบน LIFF: ถ่ายรูปผู้ใช้อัปโหลดไปยังเซิร์ฟเวอร์
  2. Face Embedding Generation: ใช้ DeepFace โหลดโมเดล (เช่น ArcFace, VGG-Face) สกัดค่าลักษณะใบหน้าออกมาเป็นเวกเตอร์ตัวเลข 128 หรือ 512 มิติ
  3. Cosine Distance Comparison: คำนวณความห่างของเวกเตอร์ใบหน้าใหม่เทียบกับใบหน้าที่ลงทะเบียนไว้ หากความต่างต่ำกว่าค่า Threshold (เช่น < 0.40) จะถือว่าเป็นบุคคลเดียวกัน
# ตัวอย่างโครงสร้างการสแกนเปรียบเทียบใบหน้า
from deepface import DeepFace

def verify_user_face(img_path_1, img_path_2):
    result = DeepFace.verify(
        img1_path=img_path_1, 
        img2_path=img_path_2, 
        model_name="ArcFace",
        enforce_detection=False
    )
    return result["verified"], result["distance"]
🤝

2. ระบบวิเคราะห์จับคู่ (Tutor Matching Algorithm)

เราขับเคลื่อนการค้นหาด้วย Semantic Search เพื่อไม่ให้ยึดติดกับคำค้นหาตรงๆ:

  1. แปลงประวัติติวเตอร์เป็นเวกเตอร์: รวมข้อมูล "ประวัติการศึกษา + วิชาถนัด + สไตล์การสอน + วิธีการสอน" แล้วประมวลผลเป็น Vector Embedding ด้วย Sentence Transformers
  2. วิเคราะห์ฝั่งผู้เรียน: ความต้องการ "ต้องการเน้นสอบเข้า ม.4 วิชาวิทยาศาสตร์ พี่ผู้สอนอารมณ์ดี ไม่เครียด" จะถูกแปลงเป็นเวกเตอร์เช่นกัน
  3. Cosine Similarity: คำนวณค่าความคล้ายคลึงระหว่างเวกเตอร์ผู้เรียนและติวเตอร์ทั้งหมด ดึงรายชื่อติวเตอร์ที่ได้คะแนนสูงสุด 3 ลำดับแรก
  4. เงื่อนไขกรองเบื้องต้น (Hard Filters): นำเกณฑ์เช่น งบประมาณ ช่วงเวลาว่าง วิชาหลัก มาคัดกรองก่อนทำการ Match
📝

แผนการพัฒนาระบบทีละขั้นตอน (Implementation Steps)

โครงร่างกระบวนการพัฒนาระบบทีละขั้น จากการออกแบบฐานข้อมูลจนเปิดใช้งานจริง:

ขั้นตอนที่ 1: ตั้งค่าโครงการและจัดเตรียมสิ่งแวดล้อม (Project Setup) Step 01

ติดตั้ง Library ที่สำคัญ เช่น fastapi, uvicorn, pythainlp, face-recognition, opencv-python, pgvector, line-bot-sdk-python และเชื่อมต่อกับ LINE Developer Console สร้าง Webhook API และ LIFF App ใน Developer Console

ขั้นตอนที่ 2: สร้างระบบยืนยันตัวตนด้วยใบหน้า (Face Recognition LIFF & API) Step 02

เขียนหน้าจอ LIFF ให้สามารถเข้าใช้งานกล้องหน้ามือถือ ถ่ายรูปใบหน้าผู้ใช้งานและส่งภาพกลับไปยัง API เพื่อทำการจดจำลักษณะใบหน้าและนำมาตรวจสอบสิทธิ์ในการลงชื่อเข้าใช้งานของแอปพลิเคชัน

ขั้นตอนที่ 3: ระบบป้อนข้อมูลประวัติความถนัดของติวเตอร์ (Tutor Input System) Step 03

สร้างหน้าจอลงทะเบียนติวเตอร์บน LINE LIFF ให้ติวเตอร์ระบุ ประวัติการศึกษา, วิชาที่ถนัด, ประสบการณ์การสอน และสไตล์การสอน เมื่อบันทึกระบบจะรวบรวมข้อความความถนัดส่งเข้าโมเดล Sentence-Transformer เพื่อสร้าง Vector Embedding เก็บลงฐานข้อมูล

ขั้นตอนที่ 4: ระบบรับความต้องการของผู้เรียนและประมวลผลจับคู่ (AI Matching Engine & Result) Step 04

ผู้เรียนกรอกความต้องการในระบบ เช่น "ต้องการเรียนเลข ม.ปลาย ติวเตรียมสอบเข้าจุฬาฯ ติวเตอร์ใจเย็น" ระบบแปลงความต้องการเป็นเวกเตอร์ เปรียบเทียบเวกเตอร์ด้วยคำสั่ง Cosine Similarity บน PostgreSQL (pgvector) และแสดงผลลัพธ์ผ่าน LINE Flex Message ให้ติวเตอร์และนักเรียนเชื่อมต่อกันได้ทันที
