ระบบบริหารจัดการหมู่บ้านและนิติบุคคลอัจฉริยะ

คู่มือโครงสร้างทางเทคนิค ฟีเจอร์ และส่วนประกอบต่างๆ ของโปรเจกต์ พฤกษา 33 (Pshome33)

📌 ภาพรวมระบบ (System Overview)

ระบบนี้เป็นเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อสนับสนุนงานของนิติบุคคลหมู่บ้านจัดสรร พฤกษา 33 ในการจัดการข้อมูลลูกบ้าน, การติดตามและจัดเก็บค่าส่วนกลาง, การตรวจสอบการชำระเงินโดยสแกนสลิปอัตโนมัติ (OCR Slip Verification), ระบบบันทึกการเข้า-ออกของผู้มาติดต่อ (Visitor), ระบบจัดการคลังพัสดุและแจ้งซ่อม, งานบริหารพนักงาน (HR/Attendance) และการจ่ายเงินเดือน (Payroll) พร้อมเชื่อมโยงกับ LINE OA และ LIFF App เพื่อสร้างช่องทางการสื่อสารที่รวดเร็วและตรวจสอบได้ให้กับลูกบ้าน

🛠️ เทคโนโลยีและสถาปัตยกรรม (Technical Stack)

  • Backend: ภาษา PHP โดยประมวลผลฐานข้อมูลผ่าน PDO (หลักๆ ทำงานร่วมกับ MySQL) และมี API รองรับข้อมูล JSON
  • Frontend: HTML5, Bootstrap CSS, Vanilla CSS (ปรับแต่งใน css/myadmin.css), jQuery, Select2 (ฟอร์มค้นหาอัจฉริยะ), DataTables (แสดงผลและค้นหาในตาราง), และ AlertifyJS (แสดงป็อปอัปแจ้งเตือน)
  • Database: โครงสร้างหลักอยู่ใน db/house_dbs.sql บันทึกรายละเอียดบ้าน สมาชิก และรายการธุรกรรมทั้งหมด
  • LINE Integration: ใช้ LINE Messaging API (LINE Bot SDK) ร่วมกับ LINE Mini App (LIFF) เพื่ออำนวยความสะดวกในการลงทะเบียน แจ้งชำระเงิน และลงเวลาทำงานพนักงาน

📁 โครงสร้างโฟลเดอร์หลัก (Key Directories)

โฟลเดอร์ / ไฟล์ คำอธิบายหน้าที่และการทำงาน
/ (Root) ไฟล์หลักสำหรับ Admin/นิติบุคคล เช่น Dashboard_admin.php, visitor_contact.php, login.php
config/ ตั้งค่าระบบและการเชื่อมต่อฐานข้อมูล เช่น connect_db.php และข้อมูลตั้งค่า Google Drive
model/ ส่วนประมวลผลเบื้องหลัง (Controller) เพื่อบันทึก/แก้ไข/ลบข้อมูลในฐานข้อมูล เช่น manage_common_fee_payment_process.php
api/ Endpoint สำหรับบริการเรียกใช้ข้อมูลในรูปแบบ JSON เพื่อเชื่อมต่อกับหน้าบ้านหรือบริการภายนอก
includes/ ส่วนประกอบหน้าเว็บส่วนกลาง (Common UI components) เช่น Header, Footer, Sidebar, Topbar
line_oa/ ส่วนของ LINE Mini App แยกเป็นระบบลูกบ้าน (house/) และพนักงานตรวจบัตร/ลงเวลา (checkin/)
engine/ สคริปต์สืบค้นข้อมูลมาทำกราฟสถิติรายเดือนและรายวัน เพื่อนำไปพ่นในหน้าแดชบอร์ดการเงิน
db/ แหล่งเก็บสคริปต์ฐานข้อมูลตั้งต้น (.sql) เช่น house_dbs.sql

⚙️ ระบบย่อยและโมดูลสำคัญ (Core Modules)

1. ระบบจัดเก็บค่าส่วนกลาง (Common Fee Payment)

ระบบสร้างและตรวจสอบการจัดเก็บค่าส่วนกลางของลูกบ้านแต่ละหลัง รองรับทั้งเงินสด โอนเงิน และผ่อนชำระ พร้อมทั้งผสานระบบตรวจสอบสลิปโอนเงิน (Slip Verification/OCR) เพื่อป้องกันการทุจริตและออก E-Receipt ทันทีหลังยืนยัน

ไฟล์หลัก: manage_common_fee_payment.php, payment_transfer.php, promptpay_verify.php

2. การเชื่อมต่อ LINE OA และ LIFF App

ลูกบ้านสามารถลงทะเบียนผ่านระบบ LINE เพื่อดูสถานะการค้างชำระ ประวัติการจ่ายเงิน และรับการแจ้งเตือนจากทางหมู่บ้านได้โดยตรงโดยไม่ต้องลงแอปเพิ่มเติม

ไฟล์หลัก: line_oa/house/register_house_user.php, line_oa/house/send_message_api.php

3. ระบบจัดการผู้มาติดต่อ (Visitor & Vehicle Tracking)

บันทึกการเข้าออกของบุคคลภายนอกที่เข้ามาในโครงการ พร้อมระบบจัดการข้อมูลยานพาหนะและการออกสติกเกอร์ที่จอดรถสำหรับรถยนต์และรถจักรยานยนต์ของลูกบ้าน

ไฟล์หลัก: visitor_contact.php, register_house_sticker.php, print_car_sticker.php

4. ระบบบริหารงานบุคคลและจ่ายเงินเดือน (HR & Payroll)

ควบคุมการทำงานของพนักงาน ตั้งแต่การบันทึกวันลาหยุด, บันทึกวันเวลาการเข้างานของพนักงานผ่านโทรศัพท์มือถือ, จนถึงคำนวณเงินเดือนรายเดือน (Payroll) หักวันลาหยุด/สาย และพิมพ์สลิปเงินเดือนแบบ PDF

ไฟล์หลัก: manage_employee.php, manage_work_time.php, payroll_generate_data.php, print_payroll_slip_pdf.php

5. คลังพัสดุส่วนกลางและการแจ้งซ่อม (Inventory & Jobs)

ควบคุมพัสดุและวัสดุอุปกรณ์ของนิติบุคคล บันทึกการรับเข้าและการเบิกจ่าย และระบบสำหรับบันทึกประวัติการบำรุงรักษาและปัญหาต่างๆ (Job Record) ในพื้นที่ส่วนกลาง

ไฟล์หลัก: manage-inventory-reciept.php, manage-inventory-withdraw.php, manage_job_record.php

6. บัญชีทั่วไปและเอกสารการเงิน (GL & Ledger)

ผังบัญชี (Chart of Accounts), การลงรายการสมุดรายวันทั่วไป (General Ledger), บันทึกใบสำคัญจ่าย (Voucher) และประมวลผลรายงานงบกำไรขาดทุนหรืองบทดลองให้เห็นสถานะทางการเงินของหมู่บ้าน

ไฟล์หลัก: manage_coa.php, manage_gl.php, manage_voucher.php, report_pnl.php

📦 การใช้งานไลบรารีภายนอก (External Integrations)

แอปพลิเคชันนี้มีการเรียกใช้ไลบรารีสำคัญผ่าน PHP Composer เพื่อความเสถียรและฟังก์ชันที่ทันสมัย:

mpdf/mpdf (ออกเอกสาร PDF ภาษาไทย) linecorp/line-bot-sdk (เชื่อมต่อ API ของ LINE) phpoffice/phpspreadsheet (อ่าน/เขียนไฟล์ Excel) thiagoalessio/tesseract_ocr (ระบบสแกนสลิป) google/apiclient (สคริปต์อัปโหลด Drive สำรองฐานข้อมูล) khanamiryan/qrcode-detector-decoder (อ่านค่า QR Code)

🗄️ โครงสร้างตารางฐานข้อมูลที่สำคัญ (Database Tables Schema)

  • ims_house_master: เก็บข้อมูลบ้านทั้งหมดในโครงการ เลขที่บ้าน เจ้าของ เนื้อที่ และค่าส่วนกลางรายเดือนที่ต้องจ่าย
  • ims_house: เก็บรายละเอียดบัญชีผู้ลงทะเบียนของแต่ละบ้านและคู่กับ Line User ID
  • ims_common_fee_payment: เก็บธุรกรรมการจ่ายเงินค่าส่วนกลาง ยอดเงิน วิธีการจ่าย และข้อมูลสลิป
  • ims_user: เก็บข้อมูลบัญชีผู้ดูแลระบบ (นิติบุคคล, กรรมการ, เจ้าหน้าที่ระบบ) และสิทธิ์การใช้งานเมนูต่างๆ
  • ims_visitor_contact: บันทึกรายละเอียดประวัติรถยนต์ บุคคลภายนอก และรายละเอียดการเข้าออก
  • ims_employee: ประวัติของพนักงานในนิติบุคคลหมู่บ้าน อัตราค่าจ้าง และตำแหน่งงาน
  • ims_work_time: ประวัติตารางเวลาบันทึกเข้างาน-ออกงานของเจ้าหน้าที่คนงาน
