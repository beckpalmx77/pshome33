คู่มือระบบชำระค่าส่วนกลางผ่าน LINE OA

รายละเอียดระบบ หน้าจอการกรอกข้อมูลชำระเงิน และการอนุมัติหลังบ้าน

1. ภาพรวมระบบ (System Overview)

ระบบชำระค่าส่วนกลางผ่าน LINE OA ได้รับการออกแบบขึ้นเพื่ออำนวยความสะดวกให้แก่ลูกบ้านในการส่งหลักฐานการโอนเงิน (Slip) เพื่อชำระค่าส่วนกลาง โดยระบบจะเชื่อมต่อข้อมูลสิทธิ์ลูกบ้าน ดึงบ้านเลขที่ อัตราค่าส่วนกลางรายเดือน และช่องทางการโอนเงินปลายทางมาแสดงผลให้อัตโนมัติ ช่วยลดขั้นตอนการกรอกข้อมูลและลดข้อผิดพลาดในการตรวจสอบของเจ้าหน้าที่นิติบุคคล

2. การทำงานฝั่งหน้าจอระบบ (payment_transfer_smart)

เมื่อลูกบ้านกดเข้าเมนู "ชำระค่าส่วนกลาง" ระบบจะเปิดผ่าน LINE LIFF และประมวลผลข้อมูลหน้าฟอร์มดังนี้:

การดึงและเตรียมข้อมูลอัตโนมัติ (LIFF Loading)

ระบบจะเรียกใช้ LINE LIFF SDK เพื่อขอรับโปรไฟล์ของลูกบ้าน และดึงเบอร์โทร/บ้านเลขที่จากตาราง ims_house_line_user และข้อมูลอัตราค่าส่วนกลางมาแสดงในช่องกรอกข้อมูลอัตโนมัติ หากไม่มีประวัติลงทะเบียนในระบบ จะแจ้งเตือนให้ไปลงทะเบียนก่อน

รายละเอียดฟิลด์และการเลือกการชำระเงิน

ลูกบ้านระบุข้อมูลการชำระเงินในฟอร์มประกอบด้วย:

  • ตัวเลือกการชำระ: เลือกชำระแบบ "รายเดือน" หรือ "รายปี"
  • จำนวนเดือนที่ชำระ: กำหนดจำนวนงวดเดือนที่ต้องการชำระ (1 - 12 งวด) โดยระบบจะนำไปคำนวณร่วมกับค่าส่วนกลางต่อเดือนเพื่อป้อนยอดเงินให้เบื้องต้น
  • งวดเดือน/งวดปี: ระบุช่วงงวดเดือนที่ประสงค์ชำระเงิน (เริ่มงวดเดือน - ถึงงวดเดือน) และปีของงวด
  • ชื่อผู้ชำระ: ระบบดึงชื่อจากฐานข้อมูลขึ้นมาแสดงให้อัตโนมัติ (สามารถแก้ไขได้)
  • จำนวนเงินที่ชำระ (บาท): ยอดเงินรวมที่โอนชำระ
  • แนบ Slip/ใบโอนเงิน: ลูกบ้านอัปโหลดไฟล์สลิปโอนเงิน (ระบบมีไลบรารีพิเศษ heic2any รองรับการแปลงไฟล์สกุล HEIC จากกล้อง iPhone เป็น JPEG อัตโนมัติเพื่อความเข้ากันได้ของระบบ)
แสดงบัญชีธนาคารปลายทาง

ข้อมูลบัญชีปลายทาง (ธนาคาร, ชื่อบัญชี, เลขที่บัญชี) จะถูกดึงมาจากข้อมูลมาสเตอร์ของนิติบุคคลโครงการ (ตาราง ims_company) มาแสดงเพื่อป้องกันความสับสน

3. กระบวนการหลังบ้านและตารางข้อมูล (Backend Processing)

เมื่อกดปุ่มส่งข้อมูล ระบบจะส่งข้อมูลแบบ AJAX ไปยังปลายทาง model/manage_payment_transfer_smart:

การตรวจสอบการส่งซ้ำ (Duplicate Submission Check)

ระบบจะตรวจเช็กตาราง ims_house_payment ด้วย "บ้านเลขที่, งวดเดือนเริ่มต้น, งวดปี" หากพบว่ามีรายการส่งสลิปรอตรวจสอบอยู่งวดดังกล่าวแล้ว ระบบจะตอบกลับรหัสความผิดพลาดเพื่อบล็อกรายการและเตือนลูกบ้านทันทีเพื่อป้องกันการส่งซ้ำซ้อน

การจัดเก็บไฟล์สลิปโอนเงิน

สลิปจะถูกเก็บเข้าสู่เซิร์ฟเวอร์ในโฟลเดอร์ uploads/slips/ และระบบจะทำการเชื่อมต่อไปยัง Google Drive API เพื่ออัปโหลดไฟล์สำรองขึ้นไปยังคลาวด์ตามโฟลเดอร์ที่ตั้งค่าไว้ใน config/google_drive_config

การบันทึกฐานข้อมูล

ข้อมูลจะบันทึกลงในตาราง ims_house_payment โดยมีการกำหนดเลขที่เอกสารในรูปแบบ P-[บ้านเลขที่]-[งวดปี]-[รันนิ่งนัมเบอร์] (เช่น P-99/99-2026-001) และตั้งค่าสถานะเริ่มต้นเป็น "รอตรวจสอบ" (N)

การตอบกลับแชท LINE (LINE Flex Message Notification)

เมื่อบันทึกข้อมูลเรียบร้อยแล้ว API จะส่งการ์ด Flex Message สรุปข้อมูลการโอนเงิน (เลขที่เอกสาร, บ้านเลขที่, งวดที่ชำระ, ยอดเงิน) ยิงตรงกลับเข้าไปยังหน้าต่างแชท LINE OA ของลูกบ้านโดยตรง เพื่อเป็นหลักฐานยืนยันความสำเร็จ

4. ขั้นตอนการตรวจสอบและอนุมัติ (Juristic Verification Flow)

ข้อมูลสลิปที่ลูกบ้านส่งมาจะเข้าสู่ระบบหลังบ้านเพื่อให้เจ้าหน้าที่นิติบุคคลตรวจสอบความถูกต้อง:

หน้าจอแสดงรายการตรวจสอบ (Pending Payments)

เจ้าหน้าที่เข้าเมนู "อนุมัติชำระเงินค่าส่วนกลาง" (หน้าจอ manage_common_fee_payment_approve) รายการที่ลูกบ้านส่งผ่าน LINE OA จะปรากฏขึ้นในสถานะรออนุมัติ พร้อมแสดงภาพสลิปที่ส่งมาเปรียบเทียบ

การอนุมัติและออกใบเสร็จ (Approval & E-Receipt)

เมื่อเจ้าหน้าที่ตรวจสอบสลิปแล้วว่ายอดเงินโอนและงวดเดือนถูกต้อง จะทำการกด "อนุมัติ" (Approve) ระบบจะทำการเปลี่ยนสถานะการชำระเงินในตาราง ims_house_payment เป็นชำระแล้ว (Y) และพิมพ์เลขที่ใบเสร็จรับเงินลงตาราง รวมถึงยิง Flex Message ใบรับเงินอิเล็กทรอนิกส์ส่งกลับเข้าสู่แชท LINE ของลูกบ้านโดยตรงเพื่อแจ้งให้ทราบทันที

หมายเหตุสำหรับผู้ดูแลระบบ
  • ไฟล์สคริปต์หลักที่ควบคุมหน้าจอลูกบ้านคือ payment_transfer_smart ในโฟลเดอร์หลัก
  • กระบวนการบันทึกข้อมูลและส่ง Flex Message ทำงานผ่าน API model/manage_payment_transfer_smart
  • ในหน้าจอชำระเงินนี้ มีการใช้ฟังก์ชันตรวจสอบโปรโมชั่นและการคำนวณส่วนลดตามนโยบายของนิติบุคคลซึ่งรันผ่านสคริปต์หลังบ้านอัตโนมัติ
