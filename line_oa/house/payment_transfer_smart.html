ภาพรวมระบบชำระค่าส่วนกลางอัจฉริยะ (System Overview) Smart LIFF Integration

หน้าจอ payment_transfer_smart.php ถูกพัฒนาขึ้นเป็นพิเศษสำหรับลูกบ้านในโครงการหมู่บ้านจัดสรร PS33 ให้สามารถแจ้งชำระเงินและส่งสลิปโอนเงินค่าส่วนกลางผ่านทาง LINE Official Account (LINE OA) ได้สะดวก ง่าย และแม่นยำสูงสุด

Auto-Profile Login

เชื่อมต่อ LINE LIFF SDK ตรวจจับตัวตนลูกบ้านอัตโนมัติ โดยไม่ต้องจำ Username/Password ระบบดึงบ้านเลขที่ ชื่อผู้พักอาศัย และอัตราค่าส่วนกลางมาให้อัตโนมัติ

Real-time Overlap Shield

มีปฏิทิน 12 เดือนตรวจสอบประวัติการชำระเงินจริงจากฐานข้อมูล แสดงสถานะ ชำระแล้ว/รอตรวจสอบ/ว่าง ทันที ป้องกันการจ่ายซ้ำซ้อน 100%

Instant Flex Receipt

เมื่อบันทึกข้อมูลเรียบร้อย ระบบจะส่งการ์ด Flex Message ยืนยันการโอนเงินกลับเข้าแชท LINE ของลูกบ้านทันที พร้อมปุ่มตรวจสอบประวัติ

กระบวนการทำงานหลัก (Workflow Pipeline)
  1. ลูกบ้านแตะเมนู "ชำระค่าส่วนกลาง" จาก Rich Menu ใน LINE OA
  2. ระบบเปิดหน้าต่าง LIFF ดึงข้อมูลบ้านเลขที่และค่าส่วนกลางจากตาราง ims_house_line_user
  3. ปฏิทิน 12 เดือนโหลดข้อมูลสถานะงวดปีจาก model/check_payment_overlap.php
  4. ลูกบ้านเลือกประเภทการชำระ (รายเดือน / รายปี) และอัปโหลดสลิป (รองรับไฟล์ HEIC จากกล้อง iPhone)
  5. ระบบส่งข้อมูลบันทึกลงตาราง ims_house_payment และอัปโหลดสลิปสำรองขึ้น Google Drive
  6. ระบบยิงการ์ด LINE Flex Message สรุปยอดเงินและเลขที่เอกสารกลับเข้าแชทลูกบ้านทันที

ตรรกะการคำนวณเงิน & แคมเปญส่วนลดรายปี (Promotion Logic) Early Bird Discount System
1. โหมดชำระรายปี (Yearly Payment)

เหมาะสำหรับลูกบ้านที่ต้องการชำระเหมาล่วงหน้าทั้งปี (12 เดือน)

  • ระบบล็อคเดือนเริ่มต้นเป็น มกราคม (1) และเดือนสิ้นสุดเป็น ธันวาคม (12) อัตโนมัติ
  • ช่องจำนวนเดือนที่ชำระจะถูกล็อคค่าเป็น 12
  • หากอยู่ในช่วงโปรโมชั่น ระบบจะคำนวณยอดเงินเพียง 11 เดือน ให้อัตโนมัติ (รับส่วนลด 1 เดือนฟรี)
2. โหมดชำระรายเดือน (Monthly Payment)

สำหรับชำระรายเดือน หรือชำระครั้งละ 2 - 11 เดือน

  • ผู้ใช้สามารถเลือกช่วงเดือนเริ่มต้น - ถึงงวดเดือน ได้อย่างอิสระ
  • ระบบมีฟังก์ชัน updateMonthLogic ซิงค์ความสัมพันธ์ระหว่างเดือนเริ่มต้น, เดือนสิ้นสุด และจำนวนเดือนให้อัตโนมัติ
  • ป้องกันการเลือกเดือนย้อนกลับ (เช่น Start > End) และแจ้งเตือนไม่ให้เลือกข้ามปี
แคมเปญส่วนลดพิเศษ: ชำระรายปีล่วงหน้า (Early Bird Promotion)

ระบบได้รับการตั้งโปรแกรมตรวจสอบวันที่ปัจจุบันแบบ Dynamic เพื่อมอบสิทธิประโยชน์ส่วนลดแก่นิติบุคคล:

ช่วงเวลาของแคมเปญ เงื่อนไขปีที่เลือก สิทธิประโยชน์ส่วนลด หมายเหตุในเอกสาร
15 ธ.ค. – 31 ธ.ค. ต้องเลือกชำระสำหรับ ปีถัดไป (Next Year) ลด 1 เดือน (จ่าย 11 เดือน) ชำระรายปีล่วงหน้า (ส่วนลด 1 เดือน)
1 ม.ค. – 31 ม.ค. เลือกชำระสำหรับ ปีปัจจุบัน (Current Year) หรือปีถัดไป ลด 1 เดือน (จ่าย 11 เดือน) ชำระรายปีล่วงหน้า (ส่วนลด 1 เดือน)
ช่วงเวลาปกติ / จ่ายย้อนหลัง เลือกปีปัจจุบัน หรือปีในอดีต (ไม่เข้าเงื่อนไข) คิดเต็ม 12 เดือนปกติ -
เมื่อลูกบ้านเปิดเข้าระบบในช่วงโปรโมชั่น ระบบจะแสดง Promotion Modal Pop-up ประชาสัมพันธ์ทันที
การอัปโหลด Slip & ระบบแปลงไฟล์ HEIC จาก iPhone อัตโนมัติ Client-side HEIC Converter

การส่งสลิปโอนเงินผ่านสมาร์ทโฟนของลูกบ้านมักประสบปัญหาความเข้ากันได้ของชนิดไฟล์ โดยเฉพาะผู้ใช้ iPhone/iPad ที่บันทึกภาพในฟอร์แมต HEIC / HEIF

ระบบแปลงภาพ HEIC อัตโนมัติ (heic2any)

ในหน้าจอ payment_transfer_smart.php ได้ผสานไลบรารี heic2any เมื่อลูกบ้านเลือกไฟล์ภาพสลิปสกุล .heic หรือ .heif ตัวสคริปต์บนเบราว์เซอร์จะทำการแปลงเป็น JPEG ให้ทันทีแบบเบื้องหลัง ก่อนส่งไปยังเซิร์ฟเวอร์

  • ไม่ต้องใช้แอปพลิเคชันแปลงภาพเสริม
  • ภาพสลิปเปิดดูได้ทันทีบนระบบหลังบ้านและทุกเบราว์เซอร์
  • รักษาคุณภาพความคมชัดของหลักฐานโอนเงิน
การจัดเก็บและสำรองข้อมูลขึ้น Google Drive

เมื่อบันทึกข้อมูลสำเร็จ ไฟล์ภาพจะถูกประมวลผลสองทางพร้อมกัน:

  • เซิร์ฟเวอร์หลัก: บันทึกเก็บในโฟลเดอร์ uploads/slips/ โดยตั้งชื่อไฟล์ด้วย Timestamp ป้องกันชื่อซ้ำ
  • Google Drive Cloud: เชื่อมต่อผ่าน util/google_drive_util.php เพื่ออัปโหลดสำรองขึ้น Cloud โครงการตาม Folder ID ที่กำหนดไว้
ข้อกำหนดและเงื่อนไขการแนบไฟล์
  • ชนิดไฟล์ที่รองรับ: JPEG, JPG, PNG, GIF และ HEIC
  • ขนาดไฟล์สูงสุด: ไม่เกิน 30 MB ต่อภาพ
  • การแสดงผลตัวอย่าง (Preview): ทันทีที่เลือกไฟล์ จะมีรูปตัวอย่างสลิปปรากฏด้านล่างเพื่อให้ลูกบ้านตรวจทานความถูกต้องก่อนกดยืนยัน

การ์ดแจ้งเตือนอัตโนมัติ (LINE Flex Message)

เมื่อลูกบ้านกดส่งข้อมูลสำเร็จ ระบบจะประมวลผลสร้างเลขที่เอกสารในรูปแบบ P-[บ้านเลขที่]-[งวดปี]-[Running] และยิงการ์ด Flex Message เข้าห้องแชทของลูกบ้านโดยตรง เพื่อเป็นหลักฐานยืนยันธุรกรรมทันที

จุดเด่นของการ์ด Flex Message:
  • แสดงโลโก้นิติบุคคลโครงการ PS33 ชัดเจน สวยงาม
  • ระบุเลขที่เอกสาร, บ้านเลขที่, ยอดเงินชำระ, ช่วงเดือน และวันเวลาทำรายการ
  • มีปุ่ม "ดูประวัติการชำระ" ที่เปิดหน้าประวัติผ่าน LINE LIFF ได้ทันที
  • หน้าต่างบันทึกข้อมูลจะทำการปิดตัวเองอัตโนมัติหลังทำรายการ 2 วินาที

ขั้นตอนการตรวจสอบและอนุมัติโดยนิติบุคคล (Juristic Approval Flow)
1 รายการรออนุมัติ

เจ้าหน้าที่นิติบุคคลเปิดหน้าจอ manage_common_fee_payment_approve รายการที่ลูกบ้านส่งผ่าน Smart Payment จะขึ้นสถานะ "รอตรวจสอบ" (Status = N)

2 เทียบสลิปกับ Statement

เจ้าหน้าที่คลิกดูภาพสลิปที่ส่งมา ตรวจสอบยอดเงิน วันที่ และบัญชีรับโอน เทียบกับยอดเงินเข้าในบัญชีธนาคารของนิติบุคคล

3 อนุมัติ & ออกใบรับเงิน

เมื่อกด "อนุมัติ" (Approve) ระบบจะเปลี่ยนสถานะเป็น ชำระแล้ว (Y) พร้อมบันทึกเลขที่ใบเสร็จรับเงิน และส่งข้อความใบเสร็จอิเล็กทรอนิกส์กลับเข้า LINE ลูกบ้าน

เปรียบเทียบความแตกต่างระหว่าง 2 หน้าจอการทำงาน payment_transfer_smart.php vs payment_transfer.php

ระบบ PS33 Home มีหน้าจอการบันทึกการชำระเงิน 2 รูปแบบ ซึ่งถูกออกแบบมาเพื่อรองรับกลุ่มผู้ใช้และอุปกรณ์ที่แตกต่างกันอย่างชัดเจน:

คุณสมบัติ / ฟังก์ชันการทำงาน payment_transfer_smart.php payment_transfer.php
1. ช่องทางการเข้าใช้งานหลัก LINE OA ผ่าน LINE LIFF SDK (สมาร์ทโฟน) Web Browser บนคอมพิวเตอร์ / แท็บเล็ต (Web Portal)
2. กลุ่มผู้ใช้งานเป้าหมาย ลูกบ้านโครงการที่ลงทะเบียนผูกบัญชี LINE แล้ว เจ้าหน้าที่นิติบุคคล / แอดมิน / ลูกบ้านบนเว็บหลัก
3. การระบุตัวตนและดึงข้อมูล ตรวจจับ LINE User ID อัตโนมัติ ล็อคบ้านเลขที่และชื่อผู้ชำระ ล็อกอินด้วยรหัสผ่าน แอดมินสามารถพิมพ์ค้นหาบ้านเลขที่ใดก็ได้
4. ปฏิทิน 12 เดือนแสดงสถานะ Real-time มี (Interactive Grid) คลิกเลือกเดือนได้ ไม่มี (ใช้การเลือก Dropdown เริ่ม-สิ้นสุด)
5. ระบบแนะนำเดือนว่างถัดไป มีปุ่มแนะนำ สลับเดือนว่างถัดไปทันที ไม่มี
6. วิธีการชำระเงินที่รองรับ โอนเงินผ่านธนาคาร (แนบสลิปบังคับ) โอนเงิน หรือ เงินสด (Cash)
7. ระบบคำนวณเงินสด & เงินทอน ไม่มี (เนื่องจากเป็นการโอนผ่านแอป) มีช่อง "รับเงินสด" และคำนวณเงินทอนอัตโนมัติ
8. การแปลงไฟล์รูปสลิป HEIC (iPhone) มี (heic2any) แปลงเป็น JPG บนเครื่องทันที Preview รูปภาพทั่วไป (JPEG / PNG)
9. การแจ้งเตือนหลังบันทึก ส่ง LINE Flex Message เข้าแชทลูกบ้านทันที แสดงข้อความ Alertify บนหน้าจอเว็บ
10. ระบบสำรองข้อมูล Google Drive บันทึก & ซิงค์ Cloud ผ่าน API บันทึกเก็บใน Server Local Directory

สาเหตุที่ 1: ช่วงงวดเดือนที่เลือกเกิดการ ทับซ้อน (Conflict) กับประวัติการชำระเงินเดิมที่ชำระแล้วหรือกำลังรอตรวจสอบอยู่ ให้สังเกตกล่องเดือนสีแดงในปฏิทิน 12 เดือน และคลิกปุ่มแนะนำเพื่อเปลี่ยนไปชำระเดือนถัดไป
สาเหตุที่ 2: ยังไม่ได้ทำการเลือกไฟล์ภาพสลิปโอนเงิน หรือยอดเงินชำระเป็น 0 บาท

เมื่อรายการถูกส่งเข้าสู่ระบบ รายการจะมีสถานะเป็น "รอตรวจสอบ" (N) ยังไม่ถือว่าการชำระเงินเสร็จสมบูรณ์ เจ้าหน้าที่นิติบุคคลสามารถตรวจสอบพบข้อผิดพลาดและทำการปฏิเสธรายการ พร้อมแจ้งให้ลูกบ้านส่งสลิปที่ถูกต้องเข้ามาใหม่ได้ผ่านระบบจัดการหลังบ้าน

ระบบออกแบบให้บันทึกรายการแยกตามปีงบประมาณเพื่อความถูกต้องของระบบบัญชีและภาษี หากต้องการชำระข้ามปี ให้ทำรายการของปีปัจจุบันให้เสร็จสิ้นก่อน แล้วจึงทำรายการของปีถัดไปแยกอีก 1 รายการ
นโยบายความคุ้มครองข้อมูลส่วนบุคคล (PDPA & Data Protection)

ไฟล์ภาพสลิปและข้อมูลการเงินจะถูกจัดเก็บในโครงสร้าง Directory ที่มีการจำกัดสิทธิ์การเข้าถึง และแสดงผลเฉพาะเจ้าของบ้านเลขที่และคณะกรรมการนิติบุคคลที่มีสิทธิ์ตรวจสอบเท่านั้น ข้อมูลทั้งหมดได้รับการเข้ารหัสและสำรองข้อมูลบน Cloud ตามมาตรฐานความปลอดภัยสากล
