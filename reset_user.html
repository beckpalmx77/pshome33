ระบบยกเลิกบัญชีผู้ใช้งานด้วยตนเอง

คู่มือสถาปัตยกรรม แนวคิด ขั้นตอน และวิธีการทำงานของระบบลงทะเบียนใหม่ (Self-Service Reset Account)

1. แนวคิดและเหตุผล (Concept & Rationale)

เมื่อเกิดกรณีที่ลูกบ้านเปลี่ยนโทรศัพท์มือถือใหม่ สมัครบัญชี LINE ใหม่ หรือมีเบอร์โทรศัพท์ใหม่ ระบบลงทะเบียนเดิมจะปฏิเสธการลงทะเบียนเนื่องจากเบอร์โทรและ LINE ID ซ้ำซ้อนกับข้อมูลที่มีอยู่ในระบบแล้ว

ปัญหาเดิม: นิติบุคคลต้องลบข้อมูลผ่านหน้าหลังบ้านให้เป็นรายคน ทำให้ล่าช้าและเพิ่มภาระงาน

แนวคิดของฟีเจอร์ยกเลิกบัญชีด้วยตัวเอง: ลูกบ้านสามารถกดยกเลิกการผูกบัญชีเดิมจากหน้าจอบน LINE Mini App (LIFF) ได้ทันที โดยระบบจะล้างข้อมูลเดิมเพื่อรองรับการลงทะเบียนใหม่ด้วย LINE บัญชีใหม่ หรือเบอร์โทรใหม่ได้ทันที สะดวก รวดเร็ว และเพิ่มความคล่องตัว 100%

2. โครงสร้างฐานข้อมูลที่เกี่ยวข้อง (Database Relationships)

เมื่อผู้ใช้งานกดยืนยันยกเลิกบัญชี ระบบจะทำธุรกรรมแบบ DB Transaction เพื่อลบข้อมูลผู้ใช้ออกจากตารางหลัก 2 ตารางดังนี้:

ชื่อตาราง ฟิลด์ข้อมูลสำคัญ บทบาท/หน้าที่
ims_house_line_user line_user_id, line_phone, house_number เก็บความสัมพันธ์การจับคู่บัญชี LINE ID เข้ากับเบอร์โทรและบ้านเลขที่ เพื่อรับข้อความแจ้งเตือนส่วนกลาง
ims_user user_id (ใช้เบอร์โทร), password (แบบ hash) บัญชีหลักในการล็อกอินเข้าระบบ
การรักษาประวัติประชากร: ตารางข้อมูลประวัติบ้านโครงการ (ims_house) จะไม่มีการลบข้อมูล เพื่อรักษาประวัติการเงินเดิมและประวัติการแจ้งซ่อมของบ้านเลขที่นั้น ๆ ไว้กับนิติบุคคลเช่นเดิม

3. ขั้นตอนการทำงาน (Step-by-Step Workflow)

1เปิดลิงก์ลงทะเบียน

เมื่อเปิดหน้าระบบลงทะเบียน line_oa/house/register_house_user.php ผ่าน LINE หากพบว่าลูกบ้านลงทะเบียนไว้แล้ว จะแสดงป๊อปอัปแจ้งสถานะการผูกบัญชีเดิม พร้อมเพิ่มปุ่ม "ยกเลิกบัญชีผู้ใช้นี้"

2ยืนยันตัวตนด้วยรหัสผ่านเดิม

เมื่อคลิกปุ่มยกเลิก ระบบจะแสดงกล่องรับข้อมูลให้กรอก "รหัสผ่านเดิม" ของบัญชี เพื่อความปลอดภัยป้องกันไม่ให้ผู้อื่นเข้ามากดยกเลิกบัญชีของลูกบ้านท่านอื่นเล่น

3การทำงานผ่าน API หลังบ้าน

ระบบส่งข้อมูลรหัสผ่านไปยัง line_oa/house/cancel_account_api.php

  • ดึงข้อมูลจากตารางผู้ใช้งานมาตรวจสอบความถูกต้องของรหัสผ่านผ่านฟังก์ชัน password_verify()
  • หากถูกต้อง จะเริ่ม Transaction ลบข้อมูลประวัติผู้ใช้ออกจากทั้ง 2 ตาราง
  • เขียนประวัติความปลอดภัยการ Deactivate บัญชีลงใน Log ไฟล์ line_house_user_register_log.txt
4รีเซ็ตหน้าจอเพื่อลงทะเบียนใหม่

เมื่อลบสำเร็จ ระบบจะแสดงการแจ้งเตือนและรีเซ็ตช่องข้อมูลฟอร์มลงทะเบียนเดิมให้สามารถสมัครสมาชิกและผูกบัญชี LINE ใหม่ หรือใส่เบอร์โทรศัพท์ใหม่ได้ทันที

4. มาตรการรักษาความปลอดภัย (Security Controls)

  • Password-Protected Deactivation: บังคับให้ลูกบ้านกรอกรหัสผ่านเพื่อจำกัดสิทธิ์ให้เฉพาะเจ้าของรหัสผ่านที่แท้จริงเท่านั้นที่กดยกเลิกบัญชีได้
  • Transactional Operations: การลบข้อมูลใช้การทำงานแบบ Database Transaction ป้องกันความผิดพลาดของข้อมูลหลงเหลือ (Orphaned Data)
  • Detailed Access Logs: ทุกการยกเลิกบัญชีจะถูกบันทึกวันเวลาและข้อมูลเบอร์โทรศัพท์ลงสู่ Log File เพื่อให้นิติบุคคลตรวจสอบย้อนหลังได้
