คู่มือการจัดการระบบ: กรณีเปลี่ยนข้อมูลบ้านเลขที่

ขั้นตอนการตรวจสอบ จัดการข้อมูลผู้อยู่อาศัย บัญชีระบบเว็บ LINE OA ยานพาหนะ และสัตว์เลี้ยง

ตารางเปรียบเทียบผลกระทบของทั้ง 4 กรณีในการจัดการระบบ

ตารางด้านล่างแสดงผลลัพธ์และความแตกต่างของการเลือกประเภทรายการเปลี่ยนสิทธิ์ในหน้าจอระบบ (เปลี่ยนสิทธิ์ผู้อยู่อาศัย) และสอดคล้องกับระบบ "ทดสอบ/ตรวจสอบผลกระทบ" บนหน้าจอจริงที่ช่วยจำลองข้อมูลผลกระทบก่อนการกดบันทึกจริง

หัวข้อ กรณี 1: เจ้าของเดิม ขายและเปลี่ยนเจ้าของใหม่ กรณี 2: เจ้าของปล่อยให้เช่า มีผู้เช่าย้ายเข้า กรณี 3: เปลี่ยนตัวผู้เช่าใหม่ (ผู้เช่าเดิมย้ายออก) กรณี 4: ย้ายบ้านข้ามบ้านเลขที่ (เช่น 67/1 ไป 67/8)

1 กรณีที่ 1: เจ้าของบ้าน ขายบ้าน และเปลี่ยนเจ้าของใหม่ (CHANGE_OWNER)
เปลี่ยนเจ้าของบ้าน

ใช้ในกรณีที่มีการโอนกรรมสิทธิ์เปลี่ยนมือเจ้าของบ้าน ณ กรมที่ดิน และมีเจ้าของบ้านคนใหม่เข้ามาแทนที่เจ้าของรายเดิมโดยสิ้นเชิง

สิ่งที่เจ้าหน้าที่ต้องระวังที่สุด:
  • ใบปลอดหนี้: ห้ามเซ็นใบปลอดหนี้หรือบันทึกข้อมูลในระบบหากบ้านเลขที่นี้มียอดค้างชำระค้างส่ง ยอดเงินค้างในตารางหนี้ต้องเป็น 0.00 บาท ก่อนทำการบันทึกเปลี่ยนสิทธิ์
  • สิทธิ์ข้อมูลส่วนบุคคล (PDPA): เนื่องจากเป็นการเปลี่ยนเจ้าของ 100% ระบบจะ ล้างการเชื่อมต่อ LINE OA ทั้งหมดของบ้านหลังนี้ทันที เพื่อความปลอดภัย ไม่ให้เจ้าของเดิมรับรู้ข้อมูลหรือแชทคุยกับนิติบุคคลแทนเจ้าของใหม่
รายการตรวจสอบก่อนเริ่มดำเนินงาน (Checklist)
ขั้นตอนการดำเนินงานในหน้าจอระบบ
  1. เปิดหน้าระบบไปที่หน้าจอ เปลี่ยนสิทธิ์ผู้อยู่อาศัย
  2. เลือกประเภทการดำเนินการเป็น "กรณี 1: เจ้าของเดิม ขายและเปลี่ยนเจ้าของใหม่ (CHANGE_OWNER)"
  3. ในช่อง "ค้นหาบ้านเลขที่ที่ต้องการดำเนินการ" ให้พิมพ์เลขที่บ้านที่ถูกขาย แล้วกดเลือกจากรายการ Autocomplete
  4. ระบบจะดึงข้อมูลลูกบ้านเดิม ยอดค้างชำระ และข้อมูลสิทธิ์ที่เชื่อมโยงอยู่ขึ้นมาแสดงที่ฝั่งขวา
  5. ระบุ "สถานะผู้อยู่อาศัยใหม่" เป็น บ้านตนเอง / เจ้าของร่วม (Owner)
  6. กรอกข้อมูล ชื่อผู้อยู่อาศัยใหม่ / ผู้ติดต่อใหม่ และ เบอร์โทรศัพท์ติดต่อใหม่ ของเจ้าของคนใหม่
  7. ที่กล่องตัวเลือกความปลอดภัย ตรวจสอบให้แน่ใจว่าได้เลือก:
    • ระงับสิทธิ์บัญชีผู้ใช้ระบบเว็บ (ims_user) ของผู้อยู่อาศัยรายเดิม
    • ยกเลิกสิทธิ์ผูก LINE OA ของผู้อยู่อาศัยเดิม
    • ระงับสิทธิ์ยานพาหนะและล้างทะเบียนรถยนต์เดิมทั้งหมด
  8. ระบุหมายเหตุการเปลี่ยนแปลง เช่น โอนกรรมสิทธิ์เปลี่ยนเจ้าของใหม่ อ้างอิงเอกสาร ทด.13 วันที่ 06/07/2026
  9. กดปุ่ม "บันทึกข้อมูลและสิทธิ์"
  10. เมื่อระบบบันทึกสำเร็จ ให้แอดมินส่งลิงก์/QR Code ลงทะเบียนของโครงการให้เจ้าของใหม่ เพื่อสแกนลงทะเบียนผูก LINE OA ต่อไป
2 กรณีที่ 2: เจ้าของบ้านปล่อยให้เช่า มีผู้เช่าเข้ามาอาศัย (Owner to Tenant)
เจ้าของปล่อยเช่า

ใช้ในกรณีที่เดิมเจ้าของอาศัยอยู่เอง แต่ต้องการเปลี่ยนมาปล่อยเช่าบ้าน โดยมีผู้เช่ารายใหม่เซ็นสัญญาเช่าย้ายเข้ามาอยู่อาศัยแทน

โครงสร้างการส่งข้อมูล LINE OA:

ระบบพึ่งพาฐานข้อมูลแยก เพื่อให้ **ผู้เช่า** สามารถใช้ LINE OA รับแจ้งพัสดุและรับข่าวสารของโครงการได้ ในขณะที่ **เจ้าของร่วม** ยังคงผูกสิทธิ์ LINE (หากสมัครไว้ต่างเบอร์) เพื่อรับใบแจ้งหนี้หรือบิลค่าส่วนกลางได้เช่นกัน ดังนั้นการปรับปรุงข้อมูลตรงนี้จะไม่ตัดสิทธิ์ LINE ของเจ้าของร่วมจริงออก

รายการตรวจสอบก่อนเริ่มดำเนินงาน (Checklist)
ขั้นตอนการดำเนินงานในหน้าจอระบบ
  1. เข้าหน้าจอ เปลี่ยนสิทธิ์ผู้อยู่อาศัย
  2. เลือกประเภทการดำเนินการเป็น "กรณี 2: เจ้าของปล่อยให้เช่า / มีผู้เช่าย้ายเข้า (MOVE_OUT_IN)"
  3. ค้นหาบ้านเลขที่ที่ต้องการทำรายการ ระบบจะโหลดประวัติฝั่งขวา
  4. ในช่อง "สถานะผู้อยู่อาศัยใหม่" ปรับให้เป็น บ้านเช่า / ผู้เช่า (Tenant)
  5. ป้อนข้อมูล ชื่อผู้อยู่อาศัยใหม่ เป็นชื่อของผู้เช่ารายใหม่ และกรอก เบอร์โทรศัพท์ติดต่อใหม่
  6. ที่กล่องความปลอดภัย ตรวจสอบให้แน่ใจว่าได้เลือก:
    • ระงับบัญชีผู้ใช้ระบบเว็บเดิมของผู้พักอาศัยเก่า (ในที่นี้คือเจ้าของที่ย้ายออก)
    • ระงับสิทธิ์ยานพาหนะและล้างทะเบียนรถยนต์เดิมทั้งหมด
  7. ระบุหมายเหตุ เช่น เจ้าของร่วมปล่อยบ้านให้เช่า ผู้เช่าย้ายเข้า สัญญาเช่าเริ่ม 06/07/2026
  8. กดปุ่ม "บันทึกข้อมูลและสิทธิ์"
  9. แนะนำผู้เช่าใหม่ให้ลงทะเบียนสิทธิ์ LINE OA พฤกษา 33 เพื่อให้ระบบดึงเบอร์โทรศัพท์นี้ไปผูกและเริ่มใช้งานรับพัสดุ
3 กรณีที่ 3: ผู้เช่าเดิมย้ายออก และมีผู้เช่าใหม่เข้ามาอาศัย (Tenant to Tenant)
เปลี่ยนผู้เช่าใหม่

ใช้ในกรณีที่บ้านเลขที่ดังกล่าวเป็นบ้านเช่าอยู่แล้ว ผู้เช่าคนเดิมหมดสัญญาเช่าและย้ายของออก และมีผู้เช่าใหม่ทำสัญญาย้ายเข้ามาอาศัยแทน

ความปลอดภัยและสิทธิ์ข้อมูลส่วนบุคคล (GDPR / PDPA):

การบันทึกรายการนี้จำเป็นต้องเลือก "ระงับสิทธิ์บัญชีผู้ใช้หน้าเว็บเดิม" และ "ยกเลิกผูกสิทธิ์ LINE" ของผู้เช่าเดิมออกทันที มิเช่นนั้นผู้เช่ารายเดิมจะยังคงสามารถเข้าดูบันทึกประวัติพัสดุ ข้อมูลแจ้งเตือน หรือเปิดบิลของบ้านเลขที่นี้ได้ ซึ่งเป็นการละเมิดความปลอดภัยของข้อมูล

รายการตรวจสอบก่อนเริ่มดำเนินงาน (Checklist)
ขั้นตอนการดำเนินงานในหน้าจอระบบ
  1. เข้าหน้าจอ เปลี่ยนสิทธิ์ผู้อยู่อาศัย
  2. เลือกประเภทการดำเนินการเป็น "กรณี 3: เปลี่ยนตัวผู้เช่าใหม่ (ผู้เช่าเดิมย้ายออก) (CHANGE_TENANT)"
  3. ค้นหาบ้านเลขที่ที่ต้องการสลับตัวผู้เช่า ตรวจสอบรายละเอียดฝั่งขวา
  4. ปรับ "สถานะผู้อยู่อาศัยใหม่" ให้ระบุเป็น บ้านเช่า / ผู้เช่า (Tenant)
  5. อัปเดตข้อมูล ชื่อผู้อยู่อาศัยใหม่ และ เบอร์โทรศัพท์ติดต่อใหม่ เป็นของผู้เช่ารายใหม่
  6. ที่การตั้งค่าความปลอดภัย ตรวจสอบให้มั่นใจว่าได้เลือก:
    • ระงับบัญชีผู้ใช้ระบบเว็บ (ims_user) ของผู้เช่าเดิมออก (อ้างอิงจากเบอร์เก่า)
    • ยกเลิกสิทธิ์ผูก LINE OA ของผู้เช่าเดิมออก
    • ระงับสิทธิ์ยานพาหนะและล้างทะเบียนรถยนต์เดิมทั้งหมด
  7. บันทึกหมายเหตุการทำงาน เช่น เปลี่ยนผู้เช่าใหม่ แทนผู้เช่าเดิมที่หมดสัญญาเช่า วันที่ 06/07/2026
  8. กดปุ่ม "บันทึกข้อมูลและสิทธิ์"
  9. นำผู้เช่าคนใหม่สแกน QR Code ลงทะเบียนรับสิทธิ์ LINE OA เพื่อเปิดการแจ้งเตือนพัสดุและข่าวสารของบ้านเลขที่นี้
4 กรณีที่ 4: ย้ายบ้านข้ามบ้านเลขที่ภายในโครงการ (เช่น ย้ายจาก 67/1 ไป 67/8)
ย้ายบ้านภายในโครงการ

ใช้ในกรณีที่ลูกบ้านท่านเดิม ย้ายที่พักอาศัยขยับขยายไปบ้านเลขที่หลังอื่นภายในโครงการ โดยต้องการนำประวัติ ข้อมูล LINE รถยนต์ และสัตว์เลี้ยงทั้งหมดตามไปด้วยโดยอัตโนมัติ

ความสะดวกและการทำงานของระบบอัตโนมัติ:

ในการดำเนินการกรณีนี้ นิติบุคคลไม่จำเป็นต้องล้างข้อมูลเดิมหรือกรอกข้อมูลผู้อยู่อาศัยใหม่ด้วยตนเอง ระบบหลังบ้านจะจัดการให้โดยอัตโนมัติ ดังนี้:

  • ล้างบ้านเลขที่เดิม (67/1): ปรับข้อมูลเป็น "บ้านว่าง", ล้างข้อมูลยานพาหนะ และปรับสถานะเป็น 'V' (Vacant)
  • สลับสิทธิ์เข้าบ้านเลขที่ใหม่ (67/8): โอนย้ายชื่อติดต่อ, เบอร์โทรศัพท์, ข้อมูลทะเบียนยานพาหนะ และสิทธิ์สติ๊กเกอร์ทั้งหมดเข้าแทนที่
  • โอนย้ายระบบ LINE OA: ปรับพิกัดบ้านเลขที่ของ LINE ID ของลูกบ้านคนนั้นในระบบให้ตรงกับบ้านหลังใหม่ทันที เพื่อให้ไม่ต้องเริ่มลงทะเบียนหรือรับ OTP ใหม่
  • โอนย้ายสัตว์เลี้ยง: ปรับพิกัดประวัติสัตว์เลี้ยงทั้งหมดตามเจ้าของย้ายไปผูกบ้านเลขที่ใหม่ทันที
รายการตรวจสอบก่อนเริ่มดำเนินงาน (Checklist)
ขั้นตอนการดำเนินงานในหน้าจอระบบ
  1. เข้าหน้าจอ เปลี่ยนสิทธิ์ผู้อยู่อาศัย
  2. ในช่องเลือกประเภทการดำเนินการ ให้เลือก กรณี 4: ย้ายบ้านข้ามบ้านเลขที่ (เช่น 67/1 ไป 67/8)
  3. ระบบจะสลับแบบฟอร์มแสดงช่องกรอกข้อมูลบ้านเลขที่เดิมและบ้านเลขที่ใหม่โดยอัตโนมัติ และซ่อนช่องกรอกประวัติอื่น ๆ เนื่องจากข้อมูลจะโอนย้ายข้ามโดยตรง
  4. ในช่อง "ค้นหาบ้านเลขที่เดิม (ย้ายออก)" ให้พิมพ์เลขบ้านหลังเก่า (เช่น 67/1) แล้วเลือกจากรายการ Autocomplete เพื่อโหลดข้อมูลปัจจุบัน
  5. ในช่อง "ค้นหาบ้านเลขที่ใหม่ (ย้ายเข้า)" ให้พิมพ์เลขบ้านหลังใหม่ (เช่น 67/8)
  6. ติ๊กตรวจสอบ Checklist ความถูกต้องทั้งสองข้อ
  7. ป้อนหมายเหตุการย้ายสิทธิ์ เช่น ลูกบ้านย้ายขยับขยายที่อยู่ภายในโครงการ จาก 67/1 ไป 67/8
  8. กดปุ่ม "บันทึกข้อมูลและสิทธิ์" และกดยืนยันในหน้าต่าง Bootbox

ข้อมูลสำหรับโปรแกรมเมอร์และการดำเนินการในระบบฐานข้อมูล (Developer Reference)

ด้านล่างคือรายละเอียดการทำงานในฐานข้อมูล SQL และตัวควบคุม PHP Controller สำหรับการดำเนินงานตามแบบโครงสร้างความสัมพันธ์ในระบบ

1. โครงสร้างตารางและฟิลด์ที่เกี่ยวข้อง (Database Schema)
  • ims_house: เก็บข้อมูลบ้านหลัก มีฟิลด์สำคัญคือ contact_name (ชื่อผู้อยู่อาศัยหลัก), phone_number (เบอร์โทร), house_status (O=Owner, R=Tenant), และ car_no1 - car_no8
  • ims_user: เก็บข้อมูลสิทธิ์ล็อกอินหน้าเว็บ ใช้ user_id (ตรงกับ phone_number) และเก็บสถานะบัญชีที่ฟิลด์ status ('Active', 'Inactive')
  • ims_house_line_user: เก็บการเชื่อมโยงระบบแจ้งเตือนไลน์ มีความสัมพันธ์ผ่านคีย์ house_number และ line_phone
  • ims_house_pet: เก็บข้อมูลสัตว์เลี้ยงสัมพันธ์กับบ้านเลขที่และลูกบ้าน
  • ims_house_change_log: เก็บประวัติการแก้ไขและเหตุผลการเปลี่ยนสิทธิ์ผู้อยู่อาศัยเพื่อใช้อ้างอิงตรวจสอบย้อนหลัง
2. ชุดคำสั่ง SQL ที่ประมวลผลเบื้องหลัง (Behind-the-Scenes SQL Commands)
A. บันทึกข้อมูล Audit Log และระงับบัญชีผู้ใช้เดิม (Cases 1, 2, 3)
-- 1. บันทึกประวัติการเปลี่ยนตัวผู้อยู่อาศัยลง Log
INSERT INTO ims_house_change_log (
    house_number, change_type, old_contact_name, old_phone_number, old_house_status, 
    new_contact_name, new_phone_number, new_house_status, remark, created_by
)
VALUES (
    :house_number, :change_type, :old_name, :old_phone, :old_status, 
    :new_name, :new_phone, :new_status, :remark, :admin_name
);

-- 2. ระงับการใช้งานบัญชีผู้ใช้ระบบเว็บ (ims_user) ของผู้อยู่อาศัยเดิม
UPDATE ims_user 
SET status = 'Inactive' 
WHERE user_id = :old_phone;

-- 3. ทำลาย Active Session เพื่อบังคับ Logout ออกจากระบบในทันที
DELETE FROM ims_user_login_logs 
WHERE user_id = :old_phone;
B. การยกเลิกสิทธิ์ผูก LINE OA (แยกตามเงื่อนไขเพื่อคงสิทธิ์เจ้าของบ้าน)
-- เงื่อนไขที่ 1: กรณี CHANGE_OWNER (ขายบ้าน) ให้ตัดสิทธิ์ LINE ทุกคนในบ้าน
UPDATE ims_house_line_user 
SET status = 'N' 
WHERE house_number = :house_number;

-- เงื่อนไขที่ 2: กรณี CHANGE_TENANT (เปลี่ยนผู้เช่า) ให้ตัดสิทธิ์เฉพาะ LINE ของคนเบอร์เก่าเท่านั้น
UPDATE ims_house_line_user 
SET status = 'N' 
WHERE house_number = :house_number 
  AND line_phone = :old_phone;
C. การจัดการประวัติสัตว์เลี้ยงและรถยนต์ (Cases 1, 2, 3)
-- 1. ยกเลิกและล้างข้อมูลรถยนต์และสติกเกอร์ที่ผูกอยู่
UPDATE ims_house 
SET 
    car_no1 = :car1, car_no1_province = :prov1, car_no1_type = :type1, car_no1_brand = :brand1, car_no1_color = :color1,
    car_no2 = '', car_no3 = '', car_no4 = '', car_no5 = '', 
    sticker_receive_status = 'N', sticker_receive_date = NULL
WHERE house_number = :house_number;

-- 2. ย้ายหรือยกเลิกสิทธิ์ข้อมูลสัตว์เลี้ยงของคนเก่า (กรณีเปลี่ยนเจ้าของบ้าน)
UPDATE ims_house_pet 
SET remark = CONCAT('ย้ายออกจากการปรับปรุงสิทธิ์เมื่อ ', NOW()) 
WHERE house_number = :house_number;

-- 3. อัปเดตข้อมูลผู้รับผิดชอบสัตว์เลี้ยงเดิม (กรณีเปลี่ยนผู้เช่าแต่สิทธิ์ดูแลยังคงอยู่)
UPDATE ims_house_pet 
SET contact_name = :new_name, phone_number = :new_phone 
WHERE house_number = :house_number;
D. การอัปเดตข้อมูลบ้านหลักเพื่อนำส่งข้อมูลใหม่เข้าตาราง
-- อัปเดตข้อมูลบ้านหลักด้วยชื่อ เบอร์โทรศัพท์ และสถานะการอยู่อาศัยใหม่
UPDATE ims_house 
SET  
    contact_name = :new_name,
    phone_number = :new_phone,
    house_status = :new_status,
    remark = :remark,
    update_by = :admin_name
WHERE house_number = :house_number;
E. การโอนย้ายสิทธิ์ข้ามบ้านเลขที่ (MOVE_HOUSE_MEMBER_SIMPLIFIED - กรณีที่ 4)

ในกรณีที่ลูกบ้านย้ายบ้านภายในโครงการ ระบบจะรันคำสั่ง SQL ดังนี้:

-- 1. เคลียร์ข้อมูลบ้านเดิมให้กลายเป็นบ้านว่าง (สถานะ 'V')
UPDATE ims_house SET 
    contact_name = 'บ้านว่าง', phone_number = '', house_status = 'V',
    car_no1 = '', car_no2 = '', car_no3 = '', car_no4 = '', car_no5 = '',
    car_no6 = '', car_no7 = '', car_no8 = '', car_no9 = '', car_no10 = '',
    sticker_receive_status = 'N',
    remark = 'ย้ายออกไปยังบ้านเลขที่ :new_house', update_by = :admin_name
WHERE house_number = :old_house;

-- 2. โอนย้ายข้อมูลผู้อยู่อาศัยและทะเบียนรถไปยังบ้านหลังใหม่ (UPDATE ในกรณีที่บ้านใหม่มีอยู่แล้ว)
UPDATE ims_house SET 
    contact_name = :old_resident_name, phone_number = :old_phone, house_status = :new_status,
    car_no1 = :old_car1, car_no2 = :old_car2, car_no3 = :old_car3, -- โอนย้ายรถยนต์ทั้งหมด
    sticker_receive_status = :old_sticker_status, remark = 'ย้ายเข้าจากบ้านเลขที่ :old_house', update_by = :admin_name
WHERE house_number = :new_house;

-- 3. ย้ายสิทธิ์การเชื่อมต่อ LINE OA ไปยังบ้านเลขที่ใหม่
UPDATE ims_house_line_user SET 
    house_number = :new_house, status = 'Y' 
WHERE line_phone = :old_phone;

-- 4. ย้ายทะเบียนและผู้รับผิดชอบสัตว์เลี้ยงไปยังบ้านเลขที่ใหม่
UPDATE ims_house_pet SET 
    house_number = :new_house, contact_name = :old_resident_name 
WHERE house_number = :old_house;
