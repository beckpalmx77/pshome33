คู่มือด้านเทคนิคระบบผู้มาติดต่อ (Visitor System)

โครงสร้างตารางข้อมูล สคริปต์ประมวลผล และการแจ้งเตือน LINE OA

1. โครงสร้างตารางจัดเก็บข้อมูล (Database Schema)

ตารางหลักที่ใช้ควบคุมและบันทึกข้อมูลการเข้า-ออกของผู้มาติดต่อคือ ims_visitor_contact ซึ่งประกอบด้วยฟิลด์ต่าง ๆ ดังนี้:

Column Name Data Type Nullable Description
id int (AUTO_INCREMENT) NO Primary Key ของข้อมูลประวัติ
house_number varchar(50) YES บ้านเลขที่อ้างอิงของลูกบ้านที่ติดต่อเข้าพบ
visitor_name varchar(200) YES ชื่อ-นามสกุล ของผู้มาติดต่อ
phone_number varchar(50) YES หมายเลขโทรศัพท์ติดต่อของ Visitor
license_plate varchar(50) YES เลขทะเบียนรถ ยานพาหนะของผู้มาติดต่อ
visitor_type varchar(50) YES ประเภทผู้ติดต่อ เช่น ส่งอาหาร, ส่งพัสดุ, ญาติ, ผู้รับเหมา
purpose varchar(200) YES วัตถุประสงค์ของการมาติดต่อขอเข้าพบ
card_exchange varchar(1) YES สถานะการแลกบัตรเข้า (Y = แลกแล้ว, N = ยังไม่ได้แลก)
card_no varchar(50) YES หมายเลขบัตรที่แลกเข้าหมู่บ้าน
card_exchange_date datetime YES วันที่และเวลาที่แลกบัตรเข้าระบบ
check_in_datetime datetime YES วันเวลาที่ทำการเช็คอิน (เข้าหมู่บ้าน)
check_out_datetime datetime YES วันเวลาที่ทำการเช็คเอาท์ (ออกจากหมู่บ้าน)
check_in_by varchar(200) YES บัญชีเจ้าหน้าที่ผู้ทำการ Check-In ผู้มาเยือน
check_out_by varchar(200) YES บัญชีเจ้าหน้าที่ผู้ทำการ Check-Out ผู้มาเยือน
check_in_status varchar(1) YES สถานะการอยู่ในพื้นที่ (Y = อยู่ในหมู่บ้าน, N = ออกแล้ว)
picture_1 - picture_5 varchar(200) YES ชื่อไฟล์รูปถ่าย 1-5 (อัปโหลดเข้าโฟลเดอร์ uploads/visitor/)
note text YES หมายเหตุ หรือรายละเอียดเพิ่มเติม
create_by varchar(200) YES ผู้สร้างรายการข้อมูลคนแรก
create_datetime datetime YES วันเวลาที่ทำรายการบันทึกแรกสุด
update_by varchar(200) YES ผู้ทำรายการแก้ไขข้อมูลล่าสุด
update_datetime datetime YES วันเวลาที่มีการแก้ไขข้อมูลล่าสุด

ดัชนีข้อมูล (Indexes) เพื่อเพิ่มความเร็วในการสืบค้น:

  • PRIMARY KEY (`id`)
  • idx_house_number (`house_number`) - ใช้เมื่อค้นหาและดึงประวัติตามบ้านเลขที่
  • idx_card_no (`card_no`) - ใช้ตรวจสอบเลขบัตรที่แลกอยู่
  • idx_check_in_status (`check_in_status`) - ใช้ดึงรายการ active visitors ในหมู่บ้าน
  • idx_check_in_datetime (`check_in_datetime`) - ใช้คัดกรองประวัติตามวันที่ของนิติบุคคล

2. ระบบแจ้งเตือนผู้อยู่อาศัย (LINE OA Integration Logic)

เมื่อผู้ติดต่อกดเช็คอิน (เข้าหมู่บ้าน) ระบบจะเชื่อมโยงข้อมูลกับตาราง ims_house_line_user เพื่อค้นหาผู้อยู่อาศัยที่ผูกระบบ LINE OA ไว้ แล้วทำการยิง Push Message แจ้งข้อมูลผู้มาเยือนให้เจ้าของบ้านทราบทันที

ตารางข้อมูล LINE User อ้างอิง (`ims_house_line_user`):

  • line_user_id (varchar) - รหัสผู้ใช้ Line (เช่น Ua2bc...)
  • house_number (varchar) - บ้านเลขที่ที่ผูกไว้
  • status (varchar) - สถานะการใช้งาน (ต้องเป็น 'Y' เพื่อใช้รับข้อความ)

สคริปต์การทำ cURL Push Notification:

$url = 'https://api.line.me/v2/bot/message/push';
$data = [
    'to' => $line_user_id,
    'messages' => [
        [
            'type' => 'text',
            'text' => $message_text // ข้อความรายละเอียดผู้ติดต่อ ทะเบียนรถ วันเวลา
        ]
    ]
];
$headers = [
    'Content-Type: application/json',
    'Authorization: Bearer ' . $line_channel_access_token
];

3. ขั้นตอนการประมวลผลและการสื่อสาร (System Workflows)

ขั้นตอนการ Check In (เข้าหมู่บ้าน)

1. หน้าจอ Smart Phone ทำการอัปโหลดไฟล์รูปถ่าย (ภาพแปลงชื่อเป็นแบบ md5 ป้องกันชื่อซ้ำ) และส่งข้อมูลฟอร์มไปยัง Action SAVE_VISITOR
2. สคริปต์ทำการตรวจสอบ หากไม่มี ID เดิมจะทำการบันทึกข้อมูลเข้าตาราง ims_visitor_contact โดยระบบจะตั้งเวลาเข้าและตั้งค่าสถานะ check_in_status = 'Y'
3. หากบันทึกข้อมูลเสร็จสิ้นและตรวจพบว่าอยู่ในหมู่บ้าน ระบบจะเรียกใช้ฟังก์ชัน sendVisitorLineNotification() เพื่อส่งแจ้งเตือนเข้า LINE OA ลูกบ้าน

ขั้นตอนการ Check Out (ออกจากหมู่บ้าน)

1. รปภ. กดปุ่ม Check Out จากแท็บรายการ หรือ นิติบุคคลกดจากระบบหลังบ้าน โดยส่งคำขอ Action CHECK_OUT พร้อมตัวแปร id
2. สคริปต์ตรวจสอบข้อมูลและทำคำสั่ง Update ตาราง ปรับปรุงสถานะ check_in_status = 'N' และเก็บค่าวันเวลาออก check_out_datetime = NOW() และระบุผู้ทำรายการออกใน check_out_by
